⇧ Tab

Shift+Tab cycles the modes for this chat: Manual, Accept edits, Plan, Auto, Bypass, then Manual again. It skips a mode the chat’s agent can’t run, like Auto on a Codex agent.

The label is a dropdown, drawn like the model button: the mode’s icon, its name and a chevron. It opens the same list as Permission mode in the + menu. Plan is the only mode with a color of its own.

When a chat picked a mode it can’t run, the label shows the mode it runs in. Bypass permissions on a current-branch chat with Only in worktrees on runs as Accept edits, and the menu says so under Bypass permissions.
