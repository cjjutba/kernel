FAQ

Questions,
answered.

Something missing? Ask on GitHub.

Is Kernel free?

Yes. Download it and use it as much as you like. Your agents' usage counts against your own plan, like any other session.

Which coding agents does it support?

Claude Code today. Support for more agents is on the roadmap.

What do I need to run it?

A Mac with Apple silicon, Claude Code signed in to a Claude plan, git, and the GitHub CLI for pull requests. Kernel checks all of this on first launch and tells you how to fix anything missing.

Does my code leave my Mac?

Only the way it already does when you use your agent and push with git. Kernel adds no servers of its own.

Can I change the team?

Yes. Agents are plain files in your repo. Edit them, add new ones, or retire one you don't need.

Does it work on Intel Macs or Windows?

Not right now. Kernel is built for Macs with Apple silicon.

Can I contribute?

Yes. Issues and pull requests are welcome on GitHub, and the contributing guide explains how to build and test it.
