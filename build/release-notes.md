The first release of Kernel, a Mac app that runs Claude Code agents as a small software team. It needs Claude Code installed and signed in, and the GitHub CLI for pull requests. Apple silicon only.

### Rooms and the floor
Add a repo as a room and its team shows up in an office view. Agents sit at desks, hand work to each other and raise a hand when they need you. Everything on the floor comes from real Claude Code events.

### Plans you approve
Brief Rowan, the lead, and get a plan back before any work starts. Once you approve it, Rowan splits it into tasks on the board and hands each one to an agent.

### Workspaces
Each task runs in its own git worktree and branch, with chats, a terminal, diffs and a checkpoint after every turn. Revert to any checkpoint without losing the chat.

### Approvals and the inbox
Risky commands, plans and questions wait for you in the inbox, on the floor or inline in the chat. Allow once, or always for that room.

### Pull requests
Agents open the PR, checks run, and you merge from Kernel. Finished workspaces move to History.

### Updates
Kernel updates itself from GitHub Releases. When a new version has downloaded, an Update ready pill appears in the footer.
