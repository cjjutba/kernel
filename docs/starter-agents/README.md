# Starter team

Kernel offers Christian, Sean, Teng and Artkin when a project has no `.claude/agents` folder yet (KERNEL-20), and Team adds any of them to a project later. Artkin reviews and can't edit. Kernel is the Lead in every project. A repo's `.claude/agents/kernel.md` customizes Kernel's instructions and tools, and Customize on Kernel's profile copies the built-in file into the repo (KERNEL-397). A repo with no reviewer gets Kernel's code review from `docs/lenses/code.md` (KERNEL-549). Until KERNEL-553 Theo was built in too, and review workspaces from then still run `legacy/theo.md` under `kernel-reviewer`. The starter reviewer is Artkin since feat-rename-starter-agents-to-christian; `legacy/theo.md` is not offered to projects. Copy any file into a repo's `.claude/agents/` and edit freely. `role` and `lead` are Kernel-only fields; Claude Code ignores them. Kernel's own instructions, such as when to share a file, come from its rules, so these files describe only the job.
