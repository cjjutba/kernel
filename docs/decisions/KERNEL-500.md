**New chat checks the issue before it sends, and Start anyway tells the Lead the user knows.** When New chat starts from an issue, from the From popover or from Start on an issue, Create calls `issues.taken` first and the button says "Checking". Findings open ConfirmIssueTaken, and the modal holds the chat in `held`: the words, the source and the picks (model, effort, plan, mode, target branch). Start anyway sends it to the room's Lead with one more line saying the user chose to start anyway, so the Lead calls create_workspace with `confirm: true` and the user isn't asked a second time. Cancel reopens New chat with the same words, source and picks, and nothing was sent. A send that fails after Start anyway goes back to New chat with the reason in a toast. KERNEL-500.

**The New chat check fails open.** An error from `issues.taken`, or no answer in 12 seconds (`TAKEN_WAIT_MS`, just over the 10 the engine gives each of its checks), starts the chat as before. If the user closes New chat while the check runs, nothing starts. An issue chip added with Link issue in the + menu doesn't set the source, so it isn't checked. KERNEL-500.
