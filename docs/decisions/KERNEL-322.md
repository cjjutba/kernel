**The composer is the one the Proposed screens draw.** Amends KERNEL-274. KERNEL-274 built the composer from the canvas's Composer artboard, while the Proposed screens, Team update, New chat and every PR screen drew a different one, and that was the redesign. Now there is one composer, and `design/redesign/Composer.png` draws it. The box sits recessed on `--input-bg`, the agent's name and role sit in a pill with no divider after it, and send and stop are circles. The canvas draws the role and the placeholder in `--faint`, which is about 3.4:1 on the box, so both stay `--muted`. The Composer and plan artboards no longer draw a plan-mode button, so it left the "Not built" list. KERNEL-322.

**Plan mode moves slowly, and only its glow loops.** Amends KERNEL-274. The maintainer wanted plan mode to feel alive without anything snapping. The glow rises from the bottom edge over 2.4s when plan mode turns on, fades over 1.6s when it turns off, and breathes every 8s while the box waits for input. Focus stops the breath and settles the glow, since a glow that moves while you type pulls your eye off the text. A plan's Copy and Approve strip opens over 1.2s, then one light crosses it once. The strip opens faster than the glow because it pushes the chat up, and text that slides for seconds feels heavy. Send changes color in 0.16s and nothing on a button loops, so Approve never pulses. The breath changes opacity only, so a chat left open all day costs a compositor layer and no repaints. With reduced motion, states jump and the glow holds still. The motion marks the mode, never progress, so it is not a status. `design/redesign/canvas/PlanMotion.dc.html` plays every step. KERNEL-322.
