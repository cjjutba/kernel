**A room's preview URLs are one list, so the Scripts page shows where it came from once, on the first row.** The list is replaced whole on every save, so a row can't come from settings.toml while its neighbour is personal. The source line sits under the first row, as SettingsRoomScripts.png draws it. Edit, Add and Remove each save the whole list to the personal file, and Remove works on rows settings.toml set too, since the personal list then replaces it. Reset shows on the first row of a list that overrides settings.toml and brings the shared list back. KERNEL-250.

**Open uses the first configured URL and never falls back to the detected one.** With URLs set, Open goes to the first, resolved with the workspace's port. If its address has a port form Kernel can't fill, Open is off and the menu row is off too, instead of opening a different URL than the one at the top of the list. With none set, Open uses the URL the first of the room's run scripts printed, and is off until one prints. The menu always ends with a Detected row, off while nothing has printed. KERNEL-250.

**`Menu` takes a `heading`.** A short title above the first item, for the Open menu's "Preview URLs" (WorkspacePreview.png). It is hidden from assistive tech, since the menu's `label` already names it. KERNEL-250.
