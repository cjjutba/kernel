**An account move that summarizes the chat first leaves one note.** The summarizing note is written again under the same id once the move is noted, so it becomes "Moved to Side, summarized from 139k to 8k tokens", and the summary's compaction writes no note of its own (Sessions holds it back through the host's `compacted`). A summary that ran on the old account has no move yet, so it shows its compaction note under that id until the move's turn replaces it. A compaction outside a move, and a move with no summary, keep their one note. A first call that re-read nothing never says "re-read 0 tokens". The cut point for a chat's size also matches the folded note, so it still counts from the summary. KERNEL-1026.
