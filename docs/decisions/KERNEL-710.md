**Kernel drops what a parent Kernel workspace left in the Mac's environment before it builds a workspace's env.** Kernel is developed inside a Kernel workspace, so its own environment holds that workspace's `KERNEL_*` names, `COMPOSE_PROJECT_NAME=kernel_<parent>` and any value filled in from the parent's slug, like a database URL. With KERNEL-449's order the Mac's environment wins over Kernel's defaults, so every workspace the child Kernel made shared the parent's Compose project. `buildEnv` now leaves out the inherited `KERNEL_*` names and every inherited value that holds the inherited `KERNEL_WORKSPACE_SLUG`. A slug is `kernel_` and 12 letters and digits, so a value the user set on the Mac doesn't hold one by chance, and a `COMPOSE_PROJECT_NAME` the user set still wins over the default. Amends KERNEL-449.
