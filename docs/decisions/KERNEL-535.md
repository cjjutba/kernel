**A long chat has a rail on its right edge, one short mark per message, that lists the first line of each message and jumps to it.** The only way back to an earlier message was scrolling by hand. The rail follows Conductor's: marks stacked at the top right, a popover on hover or keyboard focus, a click that scrolls and highlights. It lists the user's own messages. In Kernel's chat it also lists Team updates, with a shorter mark and muted text, because a Lead chat is mostly updates and a list of only the user's messages would skip most of what happened. A Team update row reads "Kai, PR ready", the teammate and the newest event, never "Team update from Kernel", which every row would repeat. It stays hidden below two messages, since one mark has nowhere to jump. `design/redesign/README.md`, Chat rail, has the sizes. KERNEL-535.

**The rail hugs the chat column's right edge instead of the thread, and its marks are 12px so they fit the 32px side padding.** With the right panel open at 1440 the 760px thread fills the column, so there is no gutter to put a rail in. A 22px button 6px in from the edge, with 12px marks, leaves 9px clear of the text and still lets the rail sit in the same place at every width. The marks rest in `--faint` rather than `--line-4`, since a mark has to be seen to be used and `--line-4` is 1.8:1 on the panel. The brighter mark is the only cue for the message in view, so the rail needs no other state. KERNEL-535.
