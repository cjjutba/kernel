**Sharing is on by default, and `experimental.sharing` stays as the way to switch it off.** Amends KERNEL-302. The card, the tab and the locked-down preview have shipped, so every agent now gets `mcp__kernel__share_file` and the Lead gets `LEAD_SHARING_RULE` with no change to settings.json. The flag keeps its place under `experimental` and still has no page in Settings. Setting it to `false` in settings.json gives each session the server and prompt it had before sharing existed, so a broken release can turn it off without a new build. Kernel writes its whole settings object back on save, so the first launch after this change writes `sharing: true` into the file. Nobody had a reason to set it before, so nobody loses a choice.

The starter agents in `docs/starter-agents/` each get one line about when to share: Kai shares an HTML mock or a screenshot of UI work, Noor a Markdown report or a diagram, Ivy screenshots of failures, Theo screenshots of visual blockers. Kernel's line repeats the Lead rule and adds that a decision which needs a picture goes to a designer or frontend engineer as an HTML mock. How to answer comments on a shared file comes with KERNEL-310. KERNEL-308.
