**Waiting icons and warning triangles are amber again.** This replaces no-amber-icons. The waiting icon (plan, question, permission) on sidebar rows and chat tabs, and every warning triangle (Settings, Checks rows, project setup, Team warnings, agent servers, the hire card, onboarding, the preview crash notice), render in `--needs-fill`. CJ found the question icon on a sidebar row hard to see: in `--ink` it looks almost the same as the branch glyphs on unread rows next to it, and unread rows are also ink with a bold title (KERNEL-508), so a chat waiting on you didn't stand out. Amber now means "needs your attention": a chat waiting on you, or something to fix. Icons use `--needs-fill` in both themes (`#f2c55c` dark, `#d97706` light), because light mode's `--needs` (`#7a4f00`) is a text value that reads brown on a 14px glyph. A chat in plan mode keeps the plan blue, except while it waits on you, when the amber waiting icon wins. The unread bold title is unchanged. The context ring and usage meters, purple for merged and the red icon states are untouched. `--tint-needs` stays removed. Reverses the icon changes of no-amber-icons and amends feat-providers-redesign, whose Settings exception now applies everywhere.
