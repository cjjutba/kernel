**A new chat with Kernel in Hand off shares one folder per project instead of making a worktree.** Making a worktree, copying files, linking dependencies and running the setup script for every chat was the cost of starting one, and a chat in Hand off only reads and plans. The folder is `<worktreeRoot>/<project>/.main`, a `git worktree add --detach` at `<remote>/<default>` as last fetched. It gets the `node_modules` link when the project asks for it, and no setup script, copied files or trust prompt. One creation promise per project means chats started together make it once. A listed folder that was deleted is pruned and made again (as in KERNEL-355).

The record has `lead: true`, `shared: true`, a `threadId`, `branch: 'HEAD'`, `baseRef` of `<remote>/<default>`, `mode: 'worktree'`, `status: 'ready'` and no ports. The first message goes at once, with no hold. Read the flag through `onSharedFolder`. A project with no commit keeps its Lead on the checkout, and a New chat that picks a target branch still gets a worktree, since a shared folder can't sit on two bases.

The folder is Kernel's and is never reset, cleaned or checked out. `MainFolder.sync` only fast-forwards it, while no chat on it is busy, after the merge fetch and at the end of a turn. Tracked changes, commits of its own or a refused fast-forward leave it as it is, with one warning per sha and reason in the activity feed, like KERNEL-181. Untracked files don't block it.

A shared chat has nothing of its own to read or clean up: Changes, diff and commits are empty, Create PR says to switch the chat to Build here first, checkpoints, the base watch, naming the branch and folder, and setup and run scripts all skip it. Archive removes no folder or branch and runs no archive script, Restore brings the chat back on the folder (made again if it is gone), and Delete in History leaves it. The folder goes with its project. Existing chats keep their worktrees, and teammates and reviews are unchanged. Switching a shared chat to Build here comes with KERNEL-1051.

Amends KERNEL-405, which gave every chat its own worktree, and brings back part of KERNEL-355 (one detached folder per project) and KERNEL-181 (it follows the latest main). KERNEL-1050.
