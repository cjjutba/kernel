**Kernel's position is delegation with the user keeping the final say, not a team of agents.** The headline is "Your AI coding agents, finally organized" and the description under it is "Say what you need, and Kernel plans it, hands it out and brings it back for your approval". Both are one line with no period, on the website hero, the page title, the social image and its alt text, and the footer. The README, `package.json` and `docs/PRODUCT.md` carry the same line, as prose where they need a period.

The old line, "Your coding agents, working as a team", was close to competitors' headlines and described the whole category rather than Kernel. "Team" also read as software for several people, while Kernel is single-user: one developer hands off coding work and approves what comes back. The hero names no specific coding agent and makes no claim about how many it supports, so the line holds as providers change. Don't put "team" back in the positioning line or add a period to the headline or description.
