**The Lead's right panel lists the room's open PRs, and the Lead has no PR header.** CJ wanted one place to see everything mergeable in a room without opening each workspace. The Lead works on the main checkout, where "No PR yet" and Create PR never apply, so its panel head is a summary instead: "N ready to merge" in the ready band, or "No open PRs" in the grey one. Clicking it opens a new PRs tab, which sits first in the Lead's strip with the ready count and is open by default. Teammates' workspaces don't have it, and `prs` shows Changes there, the way Shared does. The Lead keeps its tab in `leadRight`, apart from `right`, so opening a teammate and coming back finds the PRs tab again. There is no ⌘⇧ shortcut, since the Lead has many PRs.

The tab lists the room's workspaces that aren't archived, aren't reviews and aren't the Lead's, with a PR in any state but none, merged or closed. That covers PRs from workspaces Kernel handed off and from ones CJ started. A PR is ready when `mergeBlock` has no reason, the rule every Merge button uses (KERNEL-349), so the tab never offers a Merge the header would refuse. Ready ones come first with `MergeButton`, the rest follow muted with their state and Open. A PR that GitHub calls ready but the reviewer rule holds back reads "Waiting for approval". LeadPrs.png also shows "Waiting for approval" with "Not reviewed", which the rule doesn't produce, since a PR nobody reviewed merges as before; the row follows the rule. The list stays live through `pollPrs`, with no new polling. A PR the rule needs to read from GitHub is read once when the tab first sees it.
