**Codex shows the OpenAI mark, in ink.** Claude had its official mark on the model picker's rows and Codex had none. Codex now has the OpenAI blossom (simple-icons `openai`, the mark ChatGPT and Codex both use), and `ProviderMark` picks the mark for a provider. It sits wherever a provider is named as a heading or picked: the model picker's rows and its Claude Code and Codex group headings, the tabs in Settings, Providers, and the provider sections in Settings, Account and usage and in the Usage popover. Marks take the icon size scale (12 beside 12px text, 14 in rows and tabs, 16 beside a 15px heading) and a 6px gap.

OpenAI's brand rules allow the mark only in black or white, so it fills with `currentColor` and follows the text beside it. `--claude` stays the one brand color and is not joined by an OpenAI color. A grouped picker puts the mark on the heading only, so a row isn't marked twice. Extends claude-mark-in-model-picker.
