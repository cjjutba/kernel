**The PRs tab lists its rows title first, in three lists.** Ready to merge, Needs attention and In progress, each in the order the workspaces came in, with an empty list left out. A row's first line is the icon the sidebar shows for the PR, the title, and Merge or Merge anyway. Its second line says where the PR stands, then the agent, the PR on GitHub and its size. A ready row says its review there, since its list already says it can merge. The issue key and the Open button are gone: the title's button covers the row, so a click anywhere opens the workspace.
