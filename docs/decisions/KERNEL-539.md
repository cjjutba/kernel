**Cmd+R runs the dev script, not View, Reload.** Settings, Shortcuts has listed Cmd+R as Run dev script since the canvas, but Electron's View menu took it first and reloaded the window, which stops nothing in the main process yet throws away what's on screen. Main now hands Cmd+R to the page the way it already hands Cmd+W, and the workspace starts the room's first run script or stops the one running. View, Reload stays in the menu for a click. Outside a workspace Cmd+R does nothing. KERNEL-539

**Cmd+Enter and Cmd+Backspace answer only a permission request, and only when you're not typing.** They allow or deny the oldest permission request waiting in the open chat. A plan has its own Cmd+Shift+Enter and a question needs an answer, so neither takes them. A field with text in it keeps both keys, so Cmd+Enter in a composer set to send with Cmd+Enter still sends.
