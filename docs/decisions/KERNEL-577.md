**Dialogs scale their top offset with the window in windows taller than 900px, and stay centered on the window horizontally.** Every dialog hangs from `--modal-y` px (140 by default, 220 for confirms), its position in the canvas's 900px tall window. D-080 moved that offset up in proportion in windows under 800px tall, but nothing scaled it up, so in a tall window (CJ's is about 1340px) a dialog sat high with most of the empty space below it. Windows taller than 900px now use the same offset as short ones, `--modal-y * 100vh / 900`. At 1340px the default dialog's top is 208px and a confirm's is 327px. Between 800 and 900px nothing changes, and at exactly 900px the formula returns the canvas value, so every PNG and every shot at 1440 by 900 stays as it was. The top stays anchored, so a dialog that grows still grows downward. Dialogs are not centered vertically, because one whose height changes (a picker opening, a list loading) would jump. Horizontal placement stays as DESIGN.md has it: the scrim covers the whole window, sidebar included, and the dialog is centered on the window. `max-height` reads the scaled `--modal-top`, so a tall dialog still fits inside the window and New workspace still never scrolls. The devui stage keeps its `top: 20px !important`. Amends D-080. KERNEL-577.
