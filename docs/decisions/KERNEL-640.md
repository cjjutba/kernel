**The agents that join every room are listed and saved without a room, by the Team feature.** `agents.listGlobal` returns the personal agents in ~/.claude/agents, then plugin agents, read with `teamFiles` and the plugin list Team already caches, so they carry the same unreadable-file flags a room shows. It leaves out the checks only a room makes, such as pinned models and `cant-open-pr`. The first list waits for Claude Code's plugin list, so the page doesn't show plugin agents appearing a moment later. That first list also starts a watcher on ~/.claude/agents, and the watcher pushes `globalAgents` when the list changes. A list that changes nothing isn't sent again. `agents.saveGlobal` rewrites only a personal agent's file, and refuses a plugin agent with the message a room's save uses. Before it returns, every room Kernel has read reads its team again, so the edit shows there without waiting for that room's own watcher (KERNEL-640).
