**Every release is its own entry on the changelog, patches included.** Patches used to show inside their minor's entry as "New in x.y.z", oldest first, below the minor's own notes. After 0.2.0's 154 notes, 0.2.1 sat at the bottom of the page and the top still read "0.2.0 Latest", so a patch looked like it never shipped. CJ chose one entry per release, newest first: a patch gets its own version pill, date and "Kernel x.y.z" title, and the newest release gets the Latest badge. The landing page's pill names a patch in full ("Kernel 0.2.1 is here") and still shortens a minor ("Kernel 0.2 is here"). A patch no longer needs its x.y.0 release to exist. Amends D-058.
