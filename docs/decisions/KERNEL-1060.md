**A plan's attention count covers its task workspaces, not the plan's own approval.** The count starts when tasks are handed off, so the approval of the plan itself is the start and is not counted. Tool approvals, questions and plan approvals come from stored approvals, so a restart keeps them. Failed checks, change requests and ready PRs are Inbox rows that go when a workspace is archived, so Kernel keeps the ones that reached the user in `meta` as they arrive. A workspace counts one merge however often its PR became ready, and an expired approval counts for nothing since the user never acted on it. A plan is finished when every step has a workspace and each is merged, closed or gone. KERNEL-1060
