**Only a pending merge changes a Team update or PRs tab row, and a merged PR ignores every pending action.** Those rows draw a Merge button or the PR's state word. A merge pending on the PR reads Merging there at once, so Merge all's current row never offers Merge. A pending create, resolve, ready, reopen or update leaves the row's word alone, since no button on the row can start it. The PR band and the sidebar icon spin for any pending action in `busyLabel`'s word, and the band's ⌘⇧ keys turn off while it spins. A PR that already reads merged keeps Continue, Archive and its purple icon, because its merge is done and main clears the pending a moment after the last `pr` push. KERNEL-520.
