**Asking for a review starts Kernel's own round, with automatic review off or on.** `Reviews.requestReview` runs the same round `onReady` would, ignoring `pr.autoReview`. The Lead's `create_workspace` with `review_of` on a ready PR that has no round goes to it, so the review runs on the provider the cross-model default picks, not the named agent's. Turning automatic review on starts a round for every ready PR that has none and no open review. The Lead's instructions tell it to use `review_of` with the project's reviewer, Kernel's own reviewer included, and not to offer a new reviewer agent.
