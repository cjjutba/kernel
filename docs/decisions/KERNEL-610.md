**The app font is Geist Sans, the same family as the Geist Mono code font.** Text was Inter with its `cv01` and `ss03` alternates. A Windows version is planned, so the font has to ship with the app and look the same on every platform. That ruled out SF Pro, which Windows would replace with Segoe UI. Inter and Geist both qualify. Geist won because text and code now come from one family, and it gives Kernel a look of its own instead of the one most developer tools share. It loads from `@fontsource-variable/geist`, weights 100 to 900. The Inter-only alternates are gone. Sizes and weights don't change. Geist runs slightly wider than Inter, so text in the `design/screens/` PNGs, drawn in Inter, ends a few pixels earlier than on screen. The PNGs stay the spec for layout and copy. KERNEL-610
