**A box that starts a Lead chat opens on the Lead's pick, and follows Settings until you pick.** The New workspace modal and the room's empty New chat box show Kernel's agent file pin when it has one, else the Lead row of Settings, Models and effort (provider, model, effort) with the Lead's plan mode. They work it out on every render, so changing the Lead row changes a box nobody touched, even while it is open. The modal used to start at the effort remembered for the Lead's model (D-130) and, with none, at the Frontend and Backend row, so a Lead set to Medium still opened at High. Both boxes now fall back to the Lead's effort for a model you never picked an effort for. Engineer workspace composers keep their fallback. Amends D-130. KERNEL-544.

**A pick in the box stays with the box's draft and applies to that chat only.** Model and effort are picked together, so picking an effort keeps the model on show. Plan mode is picked on its own, and a field nobody picked keeps following the Lead. Picks are stored with the draft under the box's key (`new-chat` for the modal, `new-chat:<room>` for a room's box), in memory and in `kernel.drafts`. They outlive closing the modal, leaving the screen and a relaunch, with or without text in the box. Sending clears them with the text, and the box goes back to the Lead's pick. A pick never writes the Lead row or any other role. D-130's per-model effort memory is unchanged: an effort picked by hand is still remembered for its model, and switching model in the box starts that model at its remembered effort. KERNEL-544.

**A Lead on Codex that can't run starts the box on Claude Code's default model.** When the Lead's pick is on Codex and Codex's model list can't be read or comes back empty, the box opens on Opus 5.5 at the Lead's effort, or the nearest one Opus takes. While the list is still loading the box stays on Codex, so it doesn't flip between the two. A model picked in the box is never moved. KERNEL-544.

**The issue warning's picks still win.** Cancel on the issue-taken warning reopens New chat with the picks it held, and the box puts them in its draft as it opens. KERNEL-500, KERNEL-544.
