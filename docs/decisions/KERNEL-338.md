**A Lead chat is one sidebar row, and its tabs live in the tab row.** Rows list open Lead chats (`Thread`), not open Lead tabs, so ⌘1 to ⌘9 count chats and the workspaces their tabs handed off. Workspaces group by `Workspace.threadId`, never `leadChatId`, so a workspace stays under its chat after the tab that handed it off closes. A chat that is closed leaves its workspaces at chat level. A row's icon looks across all of its tabs: something that needs you in any tab, then a running turn in any tab (the same signals as a tab, with no timers). Folded rows are kept by thread id; fold entries saved under a chat id from before this change no longer match and rows start unfolded. KERNEL-338.

**Closing the last tab of a Lead chat closes the chat, and only that asks.** The confirm ("Close this chat?", Close chat) shows when Rowan is running in the last tab. Closing any other tab of a chat, running or not, closes it at once, where D-088 asked before closing any running chat. The issue asks for the confirm only on the last tab, and the other tabs of a chat are no longer the whole of a conversation. Other workspaces keep D-088's confirm. After the last tab closes, the chat row above it opens, or the one below when it was the first, or the room's Lead when no chat is left. Amends D-088 for the Lead's workspace. KERNEL-338.
