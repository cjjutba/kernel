**A project icon shows in its own colors.** The GitHub avatar or the picture chosen in Settings is drawn as stored, with no grayscale filter, in the sidebar, the Projects list and Settings. CJ asked for the real colors, so an icon is the one exception to the monochrome surfaces in DESIGN.md: it is the user's own image, not Kernel's chrome, and a project is easier to spot by its logo's color. The letter tile that stands in for a project without an icon stays monochrome. Amends KERNEL-241, KERNEL-255 and KERNEL-258.
