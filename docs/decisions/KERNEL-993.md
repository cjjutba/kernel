**A Lead chat's row shows its own pull request once it has one.** Amends KERNEL-600's "a row keeps its own icon". After Build here the chat's own workspace opens a PR, and the header said "Ready to merge" while the row kept the chat bubble. The row now takes the icon, tone and word a workspace row takes, in this order: what waits on you, the workspace's setup, a running turn, a PR action in flight, a local merge, then the PR's state when the workspace has a PR number or is creating one. Without a PR the row keeps the chat bubble, so a PR state of none never turns into the branch icon. The plan tint stays on the chat and plan icons only, so red, green and purple stay visible in plan mode. A folded chat never takes a teammate's PR, only their waiting approvals. `#N` sits at the row's right end and follows KERNEL-600: Archive replaces it on hover and ⌘N while ⌘ is held. The hover card reads the same glyph. Chat tabs keep their per-tab icon. KERNEL-993
