**The Linear token falls back to a plain text file only the user can read when the Keychain can't be used.** Variables (KERNEL-247) and added Claude accounts refuse to save without the Keychain. The Linear token doesn't. Before this change it always sat in plain text in `integrations.json` with mode 600, and a Mac where `safeStorage` isn't available keeps working with Linear the way it did. With the Keychain, the file holds `linearTokenEncrypted` and never the token. A plain text token from an older version is encrypted the first time Kernel reads it. The write goes through a temp file and a rename, so a crash leaves the old file or the new one and never half of either. A read that can't write still returns the token and tries again next time. A token the Keychain can't decrypt, say one encrypted on another Mac, reads as no token. Linear calls then use `LINEAR_API_KEY`, and Settings, Integrations shows Linear as not connected until the user saves the token again. KERNEL-445.
