**A role holds a model and effort for each provider, and new work starts on the other one while every signed-in account on the preferred provider is at its limit.** Amends KERNEL-406, where a role held one pick and a limit only moved work between accounts of one provider. `models.roles[role]` is `{ prefer, claude: { model, effort }, codex: { model, effort } }`. A file from before holds one `{ provider, model, effort }`, which becomes the preferred side, and the other side starts on the defaults. A Claude side takes only Claude's models and efforts, and a Codex side never a `claude-*` model. `Team.pickFor` returns the preferred side unless the provider is at its limit: its account in use has a rejected 5-hour or weekly window and `Providers.spareAccount` finds no other signed-in subscription account with room. Then it returns the other side if that provider is signed in and not at its limit either, with `fellBack` naming the provider it left, and pushes `providerFellBack` with the workspace. Only a rejected window in the limits Kernel last read triggers it, never a timer, and a window whose reset time has passed no longer counts. `providers.fallback` turns it off, on by default. A running turn is not moved: it waits for the reset, as before. KERNEL-1055.

**An agent file's pin follows the same rule, a Lead chat on Codex hands work to the role's Codex side, and a review kind's own provider falls back too.** A file's `model:` keeps its pin while its provider has room, and moves to the role's other side, the file's model and effort dropped, when it hasn't. A teammate the Lead hands off to from a chat on Codex starts on the role's Codex side. A chat on Claude carries nothing over, so a role set to Codex stays on Codex. A review keeps its reviewer role, never the Lead chat's provider. A review kind's `model` and `provider` fall back to the reviewer role's other side. A project pauses for a limit only when every provider its agents would now start on is at its limit, so a Claude limit with Codex signed in no longer pauses a project whose agents fall back. Chats already on the limited provider wait for the reset as they did. KERNEL-1055.
