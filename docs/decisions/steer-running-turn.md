**A steered message goes into the running turn, and the old Send now stays as the fallback.** While a turn runs, the box offers Queue (Enter, after the turn) and Steer (Cmd+Shift+Enter, into the turn). A queued row's button reads Steer now while the turn runs and nothing else holds the queue, and Send now otherwise. Cmd+Shift+Enter steers what is typed, and with an empty box steers the first queued message, which is what it sent before. Each runner says whether it can steer (`canSteer`). One that can't gets the old interrupt-then-send, so no provider loses the shortcut.

**Claude steers with `priority: 'next'`, and the pinned SDK only types it.** `SDKUserMessage.priority` is `'now' | 'next' | 'later'` in the pinned `sdk.d.ts` with no description. Kernel pushes `'next'`, read as "at the running turn's next step, with no interrupt". `'now'` is not used because it can mean an interrupt. Check this with the live test before bumping the SDK. Codex steers with `turn/steer` and `expectedTurnId`, so a turn that ended, has no id yet or can't be steered (a compaction) is refused.

**A steer that finds no running turn becomes an ordinary message, once.** Sessions holds a queued message out of the queue while the runner decides, so the turn ending meanwhile can't send it a second time. A refusal puts it back first in line. A message typed now that the turn can't take is sent as `chats.send` does. Its row is saved only after the turn took it, marked `steered`, with the time of the press.

**A steered row is part of the turn it joined.** The transcript does not split a turn at it, so the step in flight is not shown as cut off and the Working timer keeps counting from the turn's own message. It carries a quiet "Steered" mark.
