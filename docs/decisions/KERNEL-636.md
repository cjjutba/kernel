**Archiving the chat or workspace on screen swaps the main panel at once.** Amends KERNEL-579 and KERNEL-580 on the screen part only. The main panel used to crossfade over 200ms on top of a cloned DOM copy of the old screen. The clone could not carry everything, the composer footer among them, so for those frames the user saw a broken, footer-less version of the old screen, which read as a frame by frame flicker. The panel now swaps to the destination in one frame, as it already did under reduced motion, and no copy of the old screen is drawn. The sidebar motion stays as KERNEL-579 set it: the archived row fades and folds, Rowan's Lead row opens in its place and the destination row's selected fill fades in over `--archive-fade`. The stage `useArriving` and the sidebar read still exists, without layers (KERNEL-636).
