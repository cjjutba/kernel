**The theme checks are strict, and the baseline is gone.** The workspace screens, `prs.css` and `work.css` moved onto the type, layer and motion tokens from KERNEL-926, so `test/themeBaseline.json` and its ratchet are deleted and every file is held to zero. Inline styles that set type, color or spacing became classes: small shared ones in `tokens.css` (`gap-*`, `t-meta`, `t-code`, `t-chip`, `t-medium`, `flush`, each used by three or more screens' worth of call sites) and the one-offs in `workspace.css` and `composer.css`. `ConfirmArchive` and `HunkCard` use `Checkbox`. The workspace's menus and pickers take their arrow, Home and End keys from `listKeyAction`; the ones beside a text field use `arrowRow`, so j, k, Home and End still type. `--tint-add` was unused and is removed. `test/designParity.test.ts` keeps the add and merged colors equal to the site's.
