**New installs start in Auto, and the step after Checks is where they choose.** `DEFAULT_SETTINGS.permissions.mode` is `auto`. A chat on that default runs in Auto where its provider can run it and in Accept edits where it can't, which `effectiveMode` already decides at every step, so a Codex Lead or an account without Auto never runs a mode it doesn't have. The default changed only once the step that lets a user choose existed, as the plan said it must. KERNEL-457.

**An existing settings file stays on Accept edits.** KERNEL-432's migration pins a file with no mode to `acceptEdits` on every load. Only a file that exists is pinned, and a new install has none until something is saved, so it reads the default. `test/appSettings.test.ts` covers both, and `test/permissions.test.ts` covers the fallback. KERNEL-457.

**The step shows on a first run, and Continue always writes the mode.** Continue on Checks goes to it only when there is no room yet, as it used to go to Create your first room. A launch with rooms goes on to where the app opens. The step preselects Auto when `permissions.availability` says the Lead's provider can run it and Accept edits otherwise, with the Recommended tag on that mode. Continue saves the pick even when it is the preselected one, so a new install that went through onboarding has a saved mode and the pin never applies to it. Bypass permissions shows with its warning and is chosen like the others. Onboarding doesn't open `ConfirmBypass` on top, as KERNEL-435 says. Picking Bypass permissions here and pressing Continue calls `rememberBypassConfirmed()`, the one-time flag KERNEL-455 keeps, so no other way into Bypass asks again. The rows reuse `MODE_INFO` and `saveAppMode` from `permissionModes.ts`, so the copy and the save match Settings, Permissions. KERNEL-457.

**Skip setup leaves a gap.** A new install that skips setup and later answers a question that saves settings, such as usage data, has a file with no mode, so its next launch is pinned to Accept edits while the first ran on Auto. Accept edits is the safer of the two, so this leaves it. KERNEL-457.
