**Switching models mid-chat warns with a toast, not a line in the model picker.** Kernel calls `setModel` on the live session, which drops the prompt cache, so the next reply is slower and uses more tokens. The warning shows after `chats.configure` succeeds, only when the chat has run a turn and the new model differs from the model its last reply ran on. Switching away and back before sending shows nothing the second time, because the first model's cache is still good. The picker stays free of extra text, and a toast fits the Toasts rule for a cost the screen doesn't show. The renderer remembers the model per chat when a turn is sent, and falls back to the model the chat had when it was opened. This kind of toast stays up about 6s. KERNEL-771.
