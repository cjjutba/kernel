**The New chat box keeps its draft while it is closed.** CJ typed a prompt in New chat, pasted text and an image, pressed Escape, and opened it again to an empty box. D-100 gave each chat's composer a draft and left this box without a key, so it kept nothing. The box now keeps its draft in `composer/draftStore.ts` under the key `new-chat`, the same store chat drafts use. There is one draft for the box, not one per room. The room can change while you type, and New chat opened from another room shows the same draft with that room picked. The draft belongs to no chat, so pruning skips it. It goes to disk like a chat's draft, without image chips, so text, links and pasted text come back after a restart and images last until the app quits. A create that sends clears it, and a failed send keeps it. The picked PR, branch or issue, plan mode and branch options are not kept. Amends D-100.
