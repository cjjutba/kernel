**Comment mode draws pins and outlines in ink and canvas only, and shows the message the agent will get.** A pin is a 22px circle with a 1.5px ring and a 1px halo in the opposite tone, so it reads on a light page and on a dark one. Earlier pins are canvas-filled with an ink ring, and the pin being edited is ink-filled with a canvas ring. The hover outline is a 1.5px canvas line with a 1px ink halo and a small mono tag naming the element (`div.plan`). No color, no shadow. The page is a still while the mode is on, so the only cues are the pressed Comment button, a pill at the top of the page ("Click an element to comment", "Click a spot to comment" on an image) and a crosshair cursor. The popover is a surface-2 card with a text field, a "Noor will see" preview in mono (the first two lines of the message plus the crop chip), a hint, Cancel and Send. The preview is what the agent receives, so "You have shared v3 since." on an older version is written to the agent, not to the user. When the sharing workspace is archived the preview goes away and the popover says why Send is off, with History as the way out. HTML and image files get a Comment button, PDF and Markdown do not, and the 301 screens stay as drawn: the button only appears once comments are on. The blue header on the pricing page is page content from the shared file, not a Kernel color. KERNEL-309.
