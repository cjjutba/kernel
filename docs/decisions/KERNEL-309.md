**Comment mode draws pins and outlines in ink and canvas only, and shows the message the agent will get.** A pin is a 22px circle with a 1.5px ring and a 1px halo in the opposite tone, so it reads on a light page and on a dark one. Earlier pins are canvas-filled with an ink ring, and the pin being edited is ink-filled with a canvas ring. The hover outline is a 1.5px canvas line with a 1px ink halo and a small mono tag naming the element (`div.plan`). No color, no shadow. The page is a still while the mode is on, so the only cues are the pressed Comment button, a pill at the top of the page ("Click an element to comment", "Click a spot to comment" on an image) and a crosshair cursor. The popover is a surface-2 card with a text field, a "Noor will see" preview in mono (the first two lines of the message plus the name of the crop), a hint, Cancel and Send. The preview is what the agent receives, so "You have shared v3 since." on an older version is written to the agent, not to the user. The Where line matches KERNEL-310: the element and its selector, then the click position and the window width ("at 412, 188 in a 1280 px wide window"). The crop is named `<title>-v<n>-comment.png`. When the sharing workspace is archived the preview goes away and the popover says why Send is off, with History as the way out. The blue header on the pricing page is page content from the shared file, not a Kernel color. KERNEL-309.

**Comments depend on the file type.** An HTML page gets element pins and a crop of the page. An image gets point pins and a crop from the canvas it is drawn on. A Markdown file anchors to the block under the pointer and sends no crop. A PDF gets no Comment button: it can't show in the locked-down view (KERNEL-303), so its tab says "Open in Preview" and there is nothing in Kernel to pin. The Comment button only appears once comments are on, so the KERNEL-301 screens stay as drawn. The canvas draws HTML and image comments. Markdown follows the HTML patterns with a block outline in place of an element outline. KERNEL-309.
