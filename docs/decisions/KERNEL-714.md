**A flat dot loader replaces the rotating ring.** Every loading mark was one rotating ring, which read as generic next to the rest of the app. The loader is now a grid of dots whose opacity loops, which keeps to Motion's rule that only opacity and transform loop and stays still under reduced motion as a graded grid. It takes `--spin-ink` and otherwise `ink-2`, so it needs no hex value in light, dark or Increase contrast, and the PR header band sets `--spin-ink` to its text color (KERNEL-274). KERNEL-714.

**There are two sizes and one shape for busy and running.** `sm` is a 3x3 grid in the 11px the ring had, so buttons, tabs, sidebar rows and the footer don't move. `lg` is a 5x5 grid of 32px for loading that fills a panel: the issue lists, setup and the start screen. A button that waits and a row that runs use the same `sm`, since the word beside it says which. `Spinner` takes `label={null}` where a word is already shown, and nothing outside `ui/` draws its own ring (`test/spinnerGuard.test.ts`). KERNEL-714.

**Revised in KERNEL-740: one size that follows the text, and a quieter color.** CJ found the 5x5 `lg` grid too big (32px beside one line of 12px text) and the dots too bright, since they used near-white `ink-2` and the lit dot reached full opacity, which made the loader louder than the old ring. `lg` is gone. Every loader is the 3x3 grid, sized in `em` so it follows the text beside it (about 11px at 12 to 13px), and it always sits beside words: the issue lists, Starting Kernel and the setup rows show it next to a muted label. Dots take `--spin-ink` and otherwise `faint`, rest at 0.3 opacity and peak at 0.8 over 1.6s, and reduced motion keeps a graded grid inside the same range. KERNEL-740.

**Revised in KERNEL-755: dots fade out between beats.** Resting every dot at 0.3 kept the whole grid visible, and the dots were bigger and closer than Conductor's loader. Unlit dots now sit at opacity 0 and each dot fades up to 0.9 and back to nothing as a wave crosses the diagonals, with about two diagonals lit at once. Dots are round, 0.16em with 0.16em gaps (2px each at 12 to 13px), so the grid is 10px, no bigger than before. Reduced motion shows one dim diagonal of three dots. KERNEL-755.
