**A flat dot loader replaces the rotating ring.** Every loading mark was one rotating ring, which read as generic next to the rest of the app. The loader is now a grid of dots whose opacity loops, which keeps to Motion's rule that only opacity and transform loop and stays still under reduced motion as a graded grid. It takes `--spin-ink` and otherwise `ink-2`, so it needs no hex value in light, dark or Increase contrast, and the PR header band sets `--spin-ink` to its text color (KERNEL-274). KERNEL-714.

**There are two sizes and one shape for busy and running.** `sm` is a 3x3 grid in the 11px the ring had, so buttons, tabs, sidebar rows and the footer don't move. `lg` is a 5x5 grid of 32px for loading that fills a panel: the issue lists, setup and the start screen. A button that waits and a row that runs use the same `sm`, since the word beside it says which. `Spinner` takes `label={null}` where a word is already shown, and nothing outside `ui/` draws its own ring (`test/spinnerGuard.test.ts`). KERNEL-714.

**Revised in KERNEL-740: one size that follows the text, and a quieter color.** CJ found the 5x5 `lg` grid too big (32px beside one line of 12px text) and the dots too bright, since they used near-white `ink-2` and the lit dot reached full opacity, which made the loader louder than the old ring. `lg` is gone. Every loader is the 3x3 grid, sized in `em` so it follows the text beside it (about 11px at 12 to 13px), and it always sits beside words: the issue lists, Starting Kernel and the setup rows show it next to a muted label. Dots take `--spin-ink` and otherwise `faint`, rest at 0.3 opacity and peak at 0.8 over 1.6s, and reduced motion keeps a graded grid inside the same range. KERNEL-740.

**Revised in KERNEL-755: dots fade out between beats.** Resting every dot at 0.3 kept the whole grid visible, and the dots were bigger and closer than Conductor's loader. Unlit dots now sit at opacity 0 and each dot fades up to 0.9 and back to nothing as a wave crosses the diagonals, with about two diagonals lit at once. Dots are round, 0.16em with 0.16em gaps (2px each at 12 to 13px), so the grid is 10px, no bigger than before. Reduced motion shows one dim diagonal of three dots. KERNEL-755.

**Revised in KERNEL-759: one pattern per kind of wait.** Every loader played the same diagonal wave. `Spinner` now takes a `kind` and each kind lights the same nine dots in its own order: `action` ripples out (busy buttons, set inside `Button` and `IconButton`), `agent` keeps the diagonal and is the default, `process` sweeps columns, `load` sweeps rows and `swap` ripples in. The patterns are per-dot delays on the one `dots-wave` keyframe set, so size, speed, color and the transparent rest are unchanged. Reduced motion holds the first group of each kind. Running sidebar rows pass a `seed` from the workspace, chat or room id, a stable hash that shifts the loop so rows run out of step and keep their rhythm across renders. KERNEL-759.

**Revised after KERNEL-759: never blank, faster, same size as the icons.** In the sidebar the loader read smaller than the chat, branch and PR icons, and between waves nothing was lit: each dot was lit for a quarter of 1.6s, and the three-group kinds finished at 1.2s of a 1.6s loop. The grid is now 12px (2px dots, 3px gaps), and every kind loops in 1s, its step times its groups (5 diagonals for `agent`, 3 for the others). Each dot rises to 0.9, holds and fades out, staying above 0.5 for more than a third of the loop, so some dot is always clearly lit. Patterns, color, `--spin-ink`, the sidebar `seed` and the reduced-motion frames are unchanged, and only opacity animates. This follows KERNEL-759.

**Revised in KERNEL-759: a library of 13 patterns, one per place.** Five kinds were too few, and two of them were plain sweeps (`process` over columns, `load` over rows). `Spinner` now takes a `pattern` from 13 named ones in `ui/dotPatterns.ts` (wave, wave-back, arrow-right, arrow-down, ripple-out, ripple-in, spiral, rotate, checker, pulse, scatter, twinkle, snake), and each loading place has its own: wave for an agent working, twinkle for chat tabs, spiral for the Working line, checker for PR checks, snake for scripts, arrow-down for loading data, wave-back for switching and saving, rotate for a Banner retrying. Busy buttons and inline action links stay on ripple-out. The grid, dots, color, 12px size and 1s loop are unchanged. Every pattern lights all nine dots once per loop, is never blank (some dot is at 0.5 or more at every moment, checked against the keyframes) and rests at 0. Patterns are data (a step per dot, an optional peak for trailing dots and one of a few fade shapes), and reduced motion holds a dim still frame that shows each pattern's shape. KERNEL-759.

**Revised after KERNEL-759: dots swell instead of fading.** The loader snapped: each dot jumped to full opacity in 30 to 80ms, held, then faded, which read as blinking. Conductor's loader keeps one steady gray and changes the dots' size, so ours does too. The grid is 13px (3px round dots, 2px gaps, same 16px slot), the loop is 0.8s, and each dot scales from a pinpoint (0.18) to full size and back on a sine-like ease with no hold, so the swells overlap and roll through the grid and most dots are large at any moment. The `never blank` opacity rule is gone, and only transform animates. `arrow-right` and `arrow-down` swell for a shorter part of the loop so each chevron can be read. The 13 patterns keep their order, color (`faint` or `--spin-ink`) and the sidebar `seed`. Fade shapes (`half`, `one`, `tail`, `blink`, `beat`) are removed, since a pattern is now only an order. Reduced motion draws no animation: the still-frame dots show at full size and the rest at 0.35 scale. Follows PR #727.
