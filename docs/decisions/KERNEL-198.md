**Every step in a chat is a row that opens in place to what the agent did, and the folded "N tool calls" list collapses each of its rows.** Only some rows opened before, and nothing said which: a Thinking row was cut off and couldn't open, a tool row opened only when it had output, and the folded list printed every tool's output at once while counting thinking and earlier messages it never showed. Now thinking, every tool call and the earlier text messages in a folded list are one component, a button with `aria-expanded` and `aria-controls`, closed until it is clicked or reached with Enter or Space. A chevron, the same `.chev` as the list's header, shows at the right end of the row on hover and keyboard focus and stays while the row is open; it takes its room at rest, so a row never shifts when it appears. A row with nothing to show has no chevron and doesn't open. Thinking opens to its full text, wrapped, in the muted ink the row already uses. A tool opens to its input, then its output, both in the `.tool-out` code block: the full command for Bash, `-` and `+` lines for Edit in the delete and add tokens, the path then the content for Write, the path with offset and limit for Read, the pattern and path for Grep and Glob, the prompt for Agent and Task, and indented JSON for anything else, MCP tools included. A running tool opens to its input, a failed one keeps its red icon, and an item saved before inputs were kept opens to its output. When the output was cut, a muted line ends it: "Output cut at 20,000 characters". Open state is local to the row and keyed by the item, so a tool going from running to done stays open. The folded list renders `block.items` in order with the same rows, without the icon, with each tool's Edit and Write `+N -N` or duration on the right, and nothing printed until a row is opened. An earlier text message in that list is a row labelled "Message", a new word the canvas doesn't draw, with its first line as the preview. An opened row scrolls past 260px, in the list too.
