**A local merge reuses `pr/model.ts`, so its words and tones are the PR's.** A branch that merges on the Mac takes Merge conflicts, Resolving and Merging from `PR_STATUS` and adds only two words of its own: Behind main (grey, nothing failed) and Can't merge (red). The band, the sidebar icon, the Checks tab and the chat row all read `localStatus` and `localStand`, and `headerView` takes an optional local argument instead of a second table. A local branch never shows the PR glyph or a Create PR button, because the branch is what merges. KERNEL-478.

**Behind main offers Update branch, not Merge, though the engine would merge a clean branch.** KERNEL-441 drew Update branch and left the choice to the engine, and KERNEL-467 let the engine merge a behind branch, so its note said the panel would offer Merge in place of Update branch. The issue and `PrLocalBehind.png` ask for Update branch, so a behind branch is never merged onto a base it hasn't seen. Update branch sends the agent a message to rebase onto the base (`pr.update`, `Prs.updateBranch`) and changes no state, so the band reads Behind until the next read finds the branch caught up. Switching to Merge is one line, the button in `localHeaderView`. Amends KERNEL-467. KERNEL-478.

**"Can't merge" comes from git's read of the main checkout, not from a failed attempt.** `PrInfo.local.checkout.dirty` is what `land` checks before it moves main, so a branch whose main folder has uncommitted changes reads Can't merge on the red band as soon as Kernel sees them, with the files and their status letters, and returns to Ready to merge once they are clean. A dirty checkout wins over Behind, since the user can fix it and it blocks the merge. Try again runs the merge, so a user who just cleaned the folder doesn't wait for the next read, and a folder that is still dirty gets the engine's refusal as a toast. KERNEL-478.

**A branch with nothing committed reads "Not committed yet", or "No changes yet" with no files.** Kernel merges committed work only, and Create PR refuses in a local room, so neither state has a button. The words are the only copy the canvas doesn't draw. KERNEL-478.

**Local branches don't appear in the Lead's PRs tab or in Team updates yet.** Both list a PR by its number, which a local merge doesn't have. Showing them needs a row without a number, which the canvas doesn't draw. KERNEL-478.
