**The design PNGs and the canvas are retired, and so is Lumi.** `design/screens/`, `design/canvas/`, `design/redesign/`, `design/providers/`, `design/settings-redesign/` and `docs/SCREENS.md` are deleted. They drew old UI, yet CLAUDE.md called the PNGs the spec, so agents kept rebuilding old layouts and spent tokens reading 1440x900 images and 70KB `.dc.html` files. The spec for a task is now the screenshot or mock in its brief. Without one, an agent matches the current app and `DESIGN.md`, checks with `pnpm shots` and shares the shot. `DESIGN.md` keeps the system rules (tokens, monochrome, no status dots, purple only for merged, hairlines, one modal shell, busy buttons, type and spacing) and drops the screen layouts. `design/site/` stays, because `site/` and the site workflow read from it. `pnpm shots:compare` is gone, and `pnpm shots --all` captures every fixture. The Lumi agent existed to guard canvas fidelity, so `.claude/agents/lumi.md` is removed. Decisions that cite the PNGs keep their text as history.
