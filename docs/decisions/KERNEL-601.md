**The sidebar draws KERNEL-600's chat groups, and the rules its canvas could not show are settled here.** Amends KERNEL-205 and KERNEL-207. Each open chat and the workspaces it started are one `.nav-group`. The guide belongs to the group, so `--line-4` follows the group that holds the open row through `:has`. The Lead's row, which shows while no chat is open, and the workspaces no open chat owns are blocks of their own, each 8px under the one above. When every row of a block folds, as when a chat is archived, the block folds as one box, so its 5px above closes with it and the rows below move as they did before groups. Every spinning state goes to the right end, not only a running turn. Setting up and a PR's checks, merge or resolve show the icon the row has at rest, the PR icon when it has one and the branch or chat icon otherwise. The state word stays in the icon's tooltip and the row's name. A chat that waits on you in one of its own tabs shows its icon and no spinner, as before. A chat folded over a hidden workspace that needs you keeps its question icon and its spinner. The diff counts show from 300px of sidebar, which is 282px of the list's content box. Below that, a row with a PR shows its PR number, so a workspace with changes and a PR never goes blank at the default width. From 300px the counts take the number's place. A title that is cut shows in full in a tooltip at any width, with the state and every count as its hint line. The row measures its title on layout, because the tooltip has to be on the row before the pointer arrives. `SidebarChatFolded` was built on the single Lead chat from before threads and drew a Lead row where its PNG draws chats, so it now uses the same chats as the Grouped screens.
