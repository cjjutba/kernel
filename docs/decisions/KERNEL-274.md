**The redesign canvas in `design/redesign/` is the spec for the workspace panel, PR states, plan mode, Team update, Ask Rowan and the new chat state.** CJ and Claude designed it on a canvas and kept Linear's palette, changing how color is used rather than the colors. The PNGs live next to their artboard sources and a render script. For those surfaces they replace the `design/screens/` PNGs, which stay as the spec everywhere else. The README's "Not built" list (a plan-mode button, a bottom-panel collapse and more terminals, an Ask Rowan close button, a centered new-chat composer) is drawn on the canvas but was left out on purpose. KERNEL-274.

**Every PR state gets a header band, a state label and icon, and the band's tone on its buttons.** Amends D-071. The top of the right panel is grey, green, red or violet by state, from the `--pr-merged-*`, `--pr-ready-*` and `--pr-fail-*` tokens. The neutral band uses the panel's own surfaces. Each state shows a label, even those that used to show only the link (Open, Ready to merge, Merge conflicts), so the header says where the PR stands without reading the button. Changes requested is red, as it already was in the sidebar. While Kernel creates, checks, resolves or merges, the label keeps the state's icon and only the busy button spins. `headerView` returns the label, tone and icon for every state, and its buttons are unchanged. KERNEL-274.

**A busy button in the PR header band keeps the band's tone.** Amends D-086. The rule that every busy button turns surface-3 grey was written for a neutral header. On a green or red band the grey read as a hole cut into it. Inside the band, a busy button takes the band's soft fill and edge, dims its text and colors its spinner with the band. Everywhere else busy buttons are unchanged. KERNEL-274.

**`--needs` also marks what waits on you in the sidebar.** Amends D-084. The waiting icon on a workspace, Lead or chat row (a plan to review, a question, an approval) and the Inbox count are amber, the same color the hover card's "needs you" word already had. Nothing else in the sidebar takes color beyond the diff and PR colors. KERNEL-274.

**Plan mode is a blue composer, not a hatch.** Amends D-093. The composer gets a `--plan` border, a soft glow rising from its bottom edge, a blue caret and a blue send button. There's still no chip or label, as D-093 wanted. A waiting plan keeps the blue and puts Copy and Approve in a blue strip on top, with Approve the one blue button. The New workspace modal uses the same look. KERNEL-274.
