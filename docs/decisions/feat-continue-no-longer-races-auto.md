**Continue and an archive exclude each other, and Continue wins only if it starts first.** Archive on merge archives a merged workspace a fraction of a second after the merge, and Continue pressed in that window either failed on the removed worktree or switched the branch while the archived record kept the old one. Continue now refuses a workspace that is archived or whose archive has started, before it touches git, and says so. Once Continue has started, Archive on merge skips the workspace, because it is about to stop being merged work, and Continue clears its mark when it finishes. The guard is a per-workspace set in the PRs feature rather than the room's branch lock: the lock covers only the branch pick, and holding it across an archive would block every new workspace and fork in the room behind a git cleanup. Archive on merge stays on by default.
