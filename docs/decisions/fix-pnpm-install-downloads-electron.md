**`pnpm install` downloads Electron's binary, because `pnpm dev` can't.** Amends KERNEL-223. Since Electron 42 the `electron` package fetches its binary the first time something loads it. `pnpm test` loads it through Electron's own `bin`, which downloads. `pnpm dev` and `pnpm start` go through electron-vite, which only reads the `path.txt` the download writes and fails with "Electron uninstall" when it's missing. So a checkout that hadn't run the tests couldn't start Kernel. The root `postinstall` now runs Electron's `install-electron`, which does nothing when the binary is already there. It is the root project's own script, so `allowBuilds` doesn't change.
