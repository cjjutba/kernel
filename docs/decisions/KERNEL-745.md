**A teammate the user mentions in a Lead message stays open until the Lead acts for them, and ask_user counts for every one.** The Lead reads "The user addressed this to Noor" after the message, and a line for each mentioned agent who doesn't take tasks or has left the team. The chat row keeps the user's parts, so only the Lead's copy carries the note. A mention of the Lead itself is dropped.

`Mentions` in `src/main/services/mentions.ts` holds the open mentions per Lead chat in memory, the way `Handoffs` holds an approved plan. create_workspace closes the mention of the agent it hands to, and message_agent closes the mention of the agent whose workspace it reached. ask_user closes them all, since it names no agent and the user decides from there. A user message or Stop closes them all too, as it does a pending hand-off. The Stop hook reminds once for each open mention, and the Stop after that drops them. When a hand-off is due as well, both reminders go in one Stop. KERNEL-749 replaces this record with the open-items one, so a restart forgets open mentions for now.
