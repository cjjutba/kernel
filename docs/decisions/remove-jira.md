**Jira is no longer a tracker, because nobody used it.** It shipped in 0.4.0 and 0.5.0 (KERNEL-462 to 474, KERNEL-503, KERNEL-680), and CJ never used it, so its code, its Settings, Integrations row, its Issues and Link issue messages and its fixtures cost upkeep for nothing. The `Tracker` interface stays as it is, so Jira can come back as one more tracker if people ask for it.

Old data loads without it. A room whose settings say `[tracker] kind = "jira"` reads as having no tracker, and a leftover `[jira]` table is ignored and left in the file. An issue source saved with `tracker: 'jira'` names no tracker Kernel has, so no room's tracker is asked about it and agents read "the issue tracker". On start, Kernel deletes `jira.json` from the data folder, so no saved Jira token is left behind. Amends KERNEL-474 and KERNEL-503.
