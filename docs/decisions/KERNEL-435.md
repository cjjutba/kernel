**Permission modes are a radio list in Settings and onboarding, and a label in the composer.** Four modes with a sentence each don't fit the segmented control Settings, Permissions had for three. The list is drawn like Big terminal's presets (a filled ring with a check marks the pick), so A6 and A8 reuse one row. Bypass permissions says in its own row what it skips, every prompt including Always ask, and what still stops it: Never allow, pushes to protected branches, network off, the agent's tools line, questions and plan approval. Only in worktrees is the switch row Big terminal already has, indented under Bypass, because Settings rows are switches and not checkboxes. In the composer the mode is a muted label after the model picker, `plan` blue for Plan and an ink hairline pill for Bypass. KERNEL-435.

**Bypass stays monochrome, and its confirm button is the one red.** DESIGN.md allows red on a final confirm button and nowhere else, so the label, the onboarding caution and the Settings row use no red. The onboarding step shows Bypass with a bordered caution block and a warning icon. `ConfirmBypass` uses the one modal shell and a danger confirm, "Use Bypass permissions". KERNEL-435.

**Bypass is confirmed once, and onboarding counts as the confirmation.** The first switch into Bypass from Settings, Shift+Tab, the mode menu or the + menu opens `ConfirmBypass`. After that it never shows again. The onboarding step already shows Bypass with its warning, so choosing it there and pressing Continue sets the same one-time flag and A8 doesn't open the modal on top. KERNEL-435.

**A mode the agent's provider can't run keeps its place and says why.** Auto is dimmed with an info line, "Auto isn't available for Codex agents yet", in Settings, in the onboarding step and in the mode menu. Settings and onboarding add what happens instead: the chat uses Accept edits. Shift+Tab skips such a mode. Onboarding preselects Accept edits with the Recommended tag when the Lead runs on Codex. KERNEL-435.

**Permission mode replaces the Plan item in the + menu.** Plan is now one stop in the Shift+Tab cycle and a row in the mode menu, so the + menu's "Enter plan mode" item becomes "Permission mode ⇧Tab", which opens the mode menu. The plan toggles on New workspace and New chat with Rowan stay. Amends D-093. KERNEL-435.

**An approval says why it asked, on one line under the command.** The line sits above the buttons with an info icon and no color: "The classifier wants you to decide: writes outside the workspace" on Claude in Auto, "Codex runs it outside its sandbox" on Codex. A card with no reason looks as it did. KERNEL-435.

**Composers on other screens don't show the mode label until they're redrawn.** `ComposerModes` is the spec for the label, and D-109 says to redraw only the screens whose markup changed. The two permission request screens carry the label because they are redrawn. Settings, Shortcuts reads "Cycle permission mode" for Shift+Tab, and was redrawn for that row. KERNEL-435.
