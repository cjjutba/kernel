**A shared file card may show a thumbnail, and the UI never names the feature.** D-062 and D-068 say a chip draws an icon and never a preview. They cover composer and transcript chips only. A card for a file an agent shared is not a chip: it is the message, and the thumbnail is what tells you whether to open it. An HTML page or an image gets a 16:10 thumbnail with a 1px line-3 border. A PDF or Markdown file gets a 36px icon tile and no thumbnail. The Team update carries the same card in a compact form, 64x40 thumbnail or 40px tile, under the teammate's row. Nothing in the UI says what the feature is called. A card and a tab show the file's title, and the right panel tab reads "Shared". The canvas draws the pages in the Workspace template's older chrome (header PR button, bottom panel), so only the new parts are spec: the tab, the card, the Shared tab in the panel and the ⌘K group.
