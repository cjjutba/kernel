**A new plan is saved as `.kernel/plans/plan.md`, then `plan-2.md` and up, instead of after its first heading.** D-092 slugged the plan's opening heading into the file name. Plan mode almost always opens with "## Context", so nearly every plan landed in `context.md`, `context-2.md` and so on, and one opening with "## Why" went to `why.md`. None of those names said the file was a plan. `savePlan` now starts every new plan at `plan.md` and takes the next free name when that one is taken. ExitPlanMode plans and the Lead's `request_plan_approval` both go through it. A revision after "Request changes" still overwrites the file of the plan it revises, and the Inbox still rewrites a deleted plan to its stored name. Plans already on disk keep their names. Amends D-092. KERNEL-767
