**Electron leaves `allowBuilds`, because it no longer has an install script.** Amends D-014. Since Electron 42 the `electron` package downloads its binary the first time its `bin` runs (`pnpm test`, `pnpm dev`, `electron-vite`), not in `postinstall`, so there is nothing for pnpm to approve. better-sqlite3 and node-pty still build at install and stay pinned. If a later Electron brings an install script back, the install fails with `ERR_PNPM_IGNORED_BUILDS` and the entry goes back. KERNEL-223.

**The folder and image pickers start where the last pick was made, until Kernel quits.** Since Electron 43 an open dialog with no `defaultPath` starts in Downloads, and macOS no longer remembers the folder for Kernel. Before that, Add folder opened wherever the user last picked from. `lastFolder()` in `src/main/picker.ts` keeps the parent of the last pick, one per picker, in memory only. A fresh launch starts in Downloads. Saving it in settings would bring back what macOS used to do across launches. Nobody has asked for that. KERNEL-223.
