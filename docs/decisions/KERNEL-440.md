**Hire, edit and retire ask "for me or for the team", and start on "for me".** D9 lets a change to an agent go to the team (a branch, a commit and a pull request) or stay with the user (`~/.claude/agents`, or a local override). Every flow that changes an agent shows both as radio rows with what each does. The choice starts on Just for me, because For the team opens a pull request on a repo other people share, and Kernel doesn't do that on a default. The confirm button names the result, so the pick is never a surprise: Create agent, Save for me, Retire Kai, Open pull request. A Personal agent's file is in `~/.claude/agents`, so its edit and retire show no For the team row. KERNEL-440.

**A warning's action sits in its line, so a Team row is not one button.** Team's rows were one button that opens the profile. A warning about a server now ends in its own action (Sign in, Try again, Turn on, Add server), and Remove ends an allowance line. The row becomes a list item with a stretched link and real buttons inside it, and the profile repeats the same servers with the same actions. A file Kernel can't read is not an agent and has no profile, so it gets a "Can't read" section under the table with the parse error and Open file. KERNEL-440.
