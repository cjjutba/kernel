**New chat's where menus open from their own button and may cover the message box. Amends KERNEL-786.** KERNEL-786 made the room, Worktree or Local and branch menus end 8px above the message box, so they never covered its toolbar. In use they opened far from the button that opened them, and the branch list covered Up next. Each menu now opens upward from its own button, 8px above it, the way the model and permission menus do, and it may overlap the box. Keyboard behavior is unchanged: arrows, Home, End, Escape and Tab. KERNEL-805.

**New chat and a chat share one toolbar.** The Hand off or Build here chip, the model, the permission mode, + and send are one component that both boxes render, so a change to it shows in both. New chat's chip starts on the room's default, else Settings, Agents, else Hand off, and a pick goes to `lead.start` as `leadMode`, which the engine uses in place of the default. The where row stays different: New chat picks the room, Worktree or Local and branch, and a chat shows where it runs. KERNEL-805.
