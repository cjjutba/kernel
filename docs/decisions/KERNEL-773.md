**In this repo, a file outside the issue's Owns is a note, not a blocker.** `.claude/agents/theo.md` no longer counts it as a broken AGENTS.md rule. Theo names the file in a note, and the Lead decides whether it stays. An audit of 46 review verdicts (PRs #634 to #706) found that about half the blockers were scope complaints, and most of those PRs had already said in their body why they touched the file. Each one cost a round of fixes, CI and another review for nothing. Code added to kernel.ts, a hex value in screen code and a missing release note still block. `BLOCKER_RULE` doesn't change, and the starter Theo and the code review never named Owns, so other repos see no difference.
