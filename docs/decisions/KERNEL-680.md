**Settings has fewer pages, and each setting lives on one of them.** Account and usage and Providers were two views of the same accounts, so they are one page, Accounts, with every account's usage windows on its row. Scripts' four switches joined Git and worktrees. A room's ten pages are eight: Files to copy, Scripts, run scripts and preview URLs are Setup and scripts, and Reviews and Instructions are Pull requests. The approval timeout is only on Permissions, the agent team hook gates are only under Agent teams on Models and effort, and the default team for new rooms is on Agents. Old routes, saved places and links in old messages redirect to the page that holds the setting now. The pages follow `design/settings-redesign/`. KERNEL-680.

**Native selects are banned in the renderer.** A `<select>` draws a macOS popup menu that matches nothing else in Kernel and can't show groups, descriptions or an action row. Every dropdown is `Select` from `ui`: a button and a `.menu` listbox, so preview cover detection and the no-drag rule still see it. It keeps the keyboard of a native select (arrows, Home and End, typing to jump, Enter or Space to pick, Escape back to the button) and flips above its button when there is no room below. `test/noNativeSelect.test.ts` fails on any `select`, `option`, `optgroup` or `datalist` element in renderer code. KERNEL-680.

**A room override names the value it falls back to.** A room's dropdown that overrides an app setting lists "Default (<app value>)" first, and picking it or pressing Reset removes the room's value. A page no longer says "the app default is" in a line under the label. KERNEL-680.

**Settings pages have no text under the title.** The title says what the page is and the sections say the rest. One-line descriptions stay only where a label can't stand alone. Where a section's values are saved is a badge on its heading instead of a sentence on every row. KERNEL-680.

**Walking and the 3D floor settings are gone.** `experimental.walking` and `experimental.floor3d` went with the floor (KERNEL-606) and nothing read them. A settings file that still has them loads without them. KERNEL-680.
