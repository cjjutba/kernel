**Shortcuts are rebound in Settings, Shortcuts, and settings.json keeps only the ones the user changed.** One list in `src/shared/hotkeys.ts` names every shortcut with its default combo (modifiers plus a physical key code, `meta+shift+KeyP`). The page, every renderer key handler, main's window keys and the keys a preview hands back to Kernel read the combo in force at key time, so a change applies without a restart. A combo another shortcut has, one macOS or text editing owns (⌘C, ⌘Q and the rest), or one without ⌘, ⌃ or ⌥ (bar ⇧Tab and the function keys) is refused with the reason. Range shortcuts (the nth chat, workspace or model) rebind their modifiers and keep the number keys. Esc stays fixed because every dialog shares it. Plain ⌘W and ⌘R are still kept from the menu after they are rebound, so neither closes the window nor reloads the page by surprise. Letters match what the layout typed, as before, and the physical key only when Option changes the character.
