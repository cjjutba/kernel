**Agents may run the live tests CJ has approved.** Amends D-023. The guard denied every Bash command that set `KERNEL_LIVE`, so CJ had to run each live test by hand. CJ asked for agents to run the approved ones. `.claude/hooks/guard.mjs` now keeps a list of approved live test files, starting with `test/terminalLead.live.test.ts`. A command that sets `KERNEL_LIVE` passes only when every test run in it names at least one file and every file it names is on the list. A run that names no file is denied, because vitest would then run every test, the unapproved live ones included. So is a command that sets `KERNEL_LIVE` without running a test, since a later command in the same shell could still pick it up. `test/live.test.ts`, the check before an SDK bump, stays off the list. The deny message names the list, so an agent knows which files it may run and asks the Lead for the rest. Adding a file to the list is CJ's call, made in a PR. KERNEL-971.
