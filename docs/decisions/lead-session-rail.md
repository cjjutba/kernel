**A chat with Kernel has a Session rail.** This amends the last sentence of KERNEL-1094's Session rail paragraph, "Lead chats have none". Since one-lead-chat a Lead chat owns a folder, can build its own change and hands work to teammates, so it has stages of its own and work out with others, and the rail is where both are read. It takes the right side under the same conditions as a teammate's (panel closed, not in New chat), and the title bar's Session toggle swaps it with the panel for Lead chats too.

**"This chat" is the chat's own stages, from the same events as a teammate's.** The first stage reads "Started" by your message, since nobody else briefed it. Set up, Building, Reviewed and Merged follow the setup run, the turn running or waiting on an approval or a question, the pull request's review state and the merge. A chat that only answered questions and changed nothing (no changed files, no pull request, none being made) shows no stages, and a chat still on the old shared main folder skips Set up. The chat's branch, port, preview and scripts rows sit under the stages when there are any.

**"Handed off" is one row per workspace the chat created.** A teammate belongs to the chat through its `threadId`, kept after that tab closes, or through `leadChatId` on an older record that has no thread. Review workspaces are left out, and so is one archived without merging. Each row has the teammate's avatar and name, the task title and a stage word from the same facts as the stages: Setting up, Building, Built, Idle, Waiting on you, In review, Merged, Closed or Failed. It opens that workspace by click or Enter. Rows waiting on an approval or a question come first, then the newest. No new IPC field was needed.

**The title bar's PR actions follow the rail.** `ownPr` is unchanged, and `PrTitleBar` still shows only while neither the rail nor the panel does, so the pull request's actions are in the rail's stages or the title bar, never both. A Lead chat with no changes and no pull request has nothing to act on, so its title bar shows no "Create PR" while the rail is on.
