**No icon is amber.** The waiting icon (plan, question, permission) on sidebar rows and chat tabs, and every warning triangle (Settings, Checks rows, room setup, Team warnings, agent servers, the hire card and onboarding), now render in `--ink`. The shape of the icon already says the state, and Kernel has no accent color, so a yellow glyph added a second signal and a one-off hue. A row that waits on you still reads brighter than the muted icons around it, and its bold unread title stays. The composer's context ring is a meter, not an icon, so it keeps `--needs` from 75% and `--del` from 90%. The `--needs` token stays for the ring, and `--tint-needs` is removed because nothing used it. The `design/screens/` PNGs still draw amber icons and are out of date for this color only. Amends KERNEL-508, KERNEL-600, KERNEL-437 and KERNEL-440.
