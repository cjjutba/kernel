**A script's exit code is stored under `scriptKey`, and each script keeps its own 400 lines.** `scriptExit` is keyed by workspace, then `setup`, `archive`, `run` for the default run script and `run:<name>` for the others. A run script may be named `setup`, so a bare name would collide with the setup script's exit. Lines carry the run script's `name` (`run` when the event has none), and the 400-line limit applies per script, so a chatty frontend can't push the backend's output out. KERNEL-249.

**Remove and rename work on the personal file only.** Settings saves to `settings.local.toml`, and removing a key there can't remove a script that only `settings.toml` defines. A script from `settings.toml` shows Edit alone, and an edit saves an override under the same name. A script with a personal value shows Remove, and Reset too when it overrides `settings.toml`. Only a personal script can be renamed, and a rename drops the old name from the personal file. KERNEL-249.

**The Run tab picks a script only when the room has more than one.** A room with just `run` looks as it did after KERNEL-274. With more, a segmented control sits above the output, and until one is picked the tab shows a running script, else the first. Run and Stop on the tab strip act on the picked script. KERNEL-249.
