**The composer's permission mode is a ghost dropdown, drawn like the model button.** It sits after the model button as the same 28px ghost button: the mode's icon at 14px in muted, its name in `ink-2` at weight 500, and a chevron. It opens the mode menu above it, lined up with the icon the way the model picker lines up with the model name, 360px wide like that picker. Permission mode in the + menu opens the same menu. No mode gets a pill. Bypass permissions looks like the other modes in the composer, and ConfirmBypass, the first time, is where it gets its warning. Plan keeps its blue on the icon, the name and the chevron, because the box is blue too. Amends KERNEL-435. KERNEL-573.

**A chat can pick a mode it can't run, and then the label shows the mode it runs in.** Bypass permissions on a current-branch chat while Only in worktrees is on runs as Accept edits (`effectiveMode`, KERNEL-447). The label says Accept edits. The menu keeps the check on the mode the chat picked, Bypass permissions, and replaces that row's description with what it runs as and why, in `ink-3`: "Runs as Accept edits, Only in worktrees is on". Only the picked row gets the reason. A mode the provider can't run, like Auto on Codex, keeps its dimmed row and its own line (KERNEL-435). KERNEL-573.
