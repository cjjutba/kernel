**Buttons answer hover and press with a color fade only.** The old hover snapped, and Primary's step from `--ink` to `--ink-hover` was too small to see. Every shared button variant now has a hover and a press, and background, border and text color fade over `--dur-fast` with `--ease-out`. There is no scale, lift or shadow. Kernel is monochrome with hairlines instead of shadows (DESIGN.md), a scale would shift neighbours in dense rows and header bands, and a color change already says "this is live" and "this is down" at 28px. Filled variants dim toward their text color with `color-mix`, as the plan bar's Approve already did, so no new color token was needed. The rules use `:where()` and `:not(:disabled)`, so a screen's own `.btn` rule still wins and a disabled or busy button stays still. Hand-rolled buttons and per-screen overrides are pass 2.
