**Open Linear issues are the ones in a triage, backlog, unstarted or started state.** Amends D-140, which counted any state type except completed and canceled as open. Linear also has a `duplicate` state type, so issues marked as duplicates showed up in the Issues list, the composer's Link issue and the New chat issue tab. `linear.issues` and the issue search now ask for `state.type in [triage, backlog, unstarted, started]` instead of excluding types, so a state type Linear adds later stays out until Kernel decides what it means. `LinearStateType` includes `duplicate`, because `linear.issue` still opens a duplicate from a workspace header or a link. The move to In Progress already starts only from triage, backlog or unstarted, so it leaves a duplicate where it is. KERNEL-172.
