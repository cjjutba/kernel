**A dev run reads What's new from the repo.** Amends KERNEL-154. A dev run has no updater and no notes in its build, so What's new opened with only its title and Done, and looked broken to the person running Kernel from main every day. A dev run now reads the running version's release file in the repo (`site/content/releases/<version>.md`) with the same parser the updater uses, and passes the notes to Kernel as `currentNotes`. The raw file reads the same as the notes a release renders for every release since 0.1.1, so the dev run shows what the installed app shows. Local `pnpm dist:mac` builds still have no notes, because the repo isn't inside them.
