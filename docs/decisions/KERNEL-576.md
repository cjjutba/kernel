**Screens pick a text tier by role, and body text is ink-2.** `body` was `ink`, so every element that set no color inherited the brightest tier. It is now `ink-2`, and the elements that are emphasis set `ink` themselves: page, modal, card and section headings, the current row, tab and chip, unread rows and tabs, bold text and inline code in a reply, and primary buttons. Rows, list items, transcript text, field values, secondary buttons and menu items are `ink-2`. Hover can still go to `ink`, which keeps icon buttons and links as DESIGN.md describes them. Text that was `faint` is `muted` (line numbers, shortcuts, counts, ids, a placeholder). `faint` stays on icons, borders, separators and disabled controls. KERNEL-576

**An inactive chat tab is ink-2, not muted.** The brief wants unread tabs as bold `ink` over a default of `ink-2`, as in the sidebar and the Inbox. The selected tab keeps `ink` and its underline, and hover goes to `ink`. Putting the tab back to `muted` is one line in `.ws-tab`. KERNEL-576

**Field borders use `--input-line`, and their focus border is `ink-3`.** `.input`, selects, the settings, issue, repo and filter search fields, the Team and Settings textareas, the comment note and the floor note moved from `line-2`, `line-3` or `faint`. The focus border was `line-4`, which is dimmer than `--input-line`, so a focused field would have lost its border. It is `ink-3`, a step above. The composer boxes (`.cmp`, `.composer`, `.floor-brief`, `.hm-ask`, Ask Rowan) are containers with a recessed fill and stay on `line-2`. Moving them to 3:1 is a design call for the Lead. KERNEL-576
