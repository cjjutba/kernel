**Images for the diff tab get a 5 MB cap, not the file viewer's 1 MB.** `workspaces.readImage` refuses images over `MAX_IMAGE_BYTES` (5 MB), where `readWorkspaceFile` stops text at `MAX_FILE_BYTES` (1 MB). A retina screenshot is often 2 or 3 MB, and 1 MB would refuse most of the images an agent adds to a repo. An image that isn't there returns null on either side, so a new image has no base and a deleted one has no worktree version. A path outside the workspace, a file type other than png, jpg, jpeg, gif, webp or svg, and an image over the cap throw instead. KERNEL-409
