**A new chat is named from its first message as soon as it is sent.** This amends D-089 and KERNEL-202. Claude Code writes its transcript title a few seconds into the turn and Kernel reads it at most every 3 seconds, so a new chat kept "New chat" for noticeably long. `Chats.nameFromFirst` now asks `titleFor` for a name from the first message right when Sessions saves it (`onSent`), in parallel with the turn, for Claude and Codex chats alike. It runs once per conversation, until /clear, and shares the `naming` guard with the turn-end request. The first name to arrive wins: both it and the transcript title save only when the stored chat is still auto-named and unnamed, so a later name never overwrites, and a name the user typed, even one typed while the request is in flight, is never replaced. /clear and stopping drop an answer that arrives late. The schedule at 1, 3, 10 and 30 finished turns is unchanged. A failed request logs once and leaves the chat to the transcript and turn-end paths. KERNEL-1024.
