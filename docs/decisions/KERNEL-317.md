**One matcher decides whether a command has `--dangerously-skip-permissions`, and the engine and the skip notice both use it.** Amends KERNEL-248. The pattern lives in `src/shared/skipFlag.ts` with no Node imports, so main and the renderer load the same file. Main uses it to list a preset as skipping permissions and to strip the flag under Only in worktrees. The notice on a big terminal tab uses it to tell whether the command that ran still has the flag. Before this, the notice checked for the text of the flag anywhere in the command, so `--dangerously-skip-permissions-x` counted as the flag there and not in main. The matcher now also takes the flag inside backticks, as in `` `claude --dangerously-skip-permissions` ``, before or after it. A quoted value (`="a b"`), a value with a command substitution (``claude "--dangerously-skip-permissions=a`b`"``) and partial quoting (`--"dangerously-skip-permissions"`) are not caught. A backtick now ends a value, so the substitution form was caught before this change and isn't any more. Typing those takes intent, and Only in worktrees guards against mistakes, not against the user. KERNEL-317.
