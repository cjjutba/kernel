**The Settings nav expands a room only while one of its pages is open.** KERNEL-191 kept the room you were in last expanded on an app page, or the first room before any, so Personal pages sat above a room with nothing highlighted under it. CJ chose to drop that. On an app page every room is a single row, and on a room page only that room is expanded. Search still expands every room that matches. This amends KERNEL-191, and `lastRoomId` in `SettingsNav.tsx` is gone with it. The Rooms block now reads as a nested list like Conductor's repository list. A room row is its avatar and name with no chevron, and clicking it still folds and unfolds the room, with `aria-expanded` set. The avatar is 16px with rounded corners, and an image avatar has no border where a letter tile keeps one. Each page has a 15px icon (`icon` in `ROOM_PAGES`), and the pages sit one step in, to the right of a 1px `--line-3` line that starts under the avatar's center. KERNEL-534.
