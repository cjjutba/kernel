**A chat's last turn is recorded from the provider's own token counts, with its first model call kept apart.** `Chat.lastTurn` holds the turn's counts (Claude's result `usage`, Codex's last `thread/tokenUsage/updated`) and `first`, the turn's first main-loop call. Only the first call says whether the turn found the chat in the cache. Later calls read what the first one wrote, so a cold turn with five tool calls has a summed `cacheRead` far above its context. The shared cache check and the move note read `first`. `context` is the chat's size after the turn's last call, else /context's `used`. Codex counts cached input inside `inputTokens`, so Kernel subtracts the reads and writes to get Claude's meaning of `input`. KERNEL-842.

**A chat with no turn on record gets its size guessed once, from its transcript since the last compaction, at 4 characters a token.** `Placement.size` saves the guess as a `lastTurn` marked `estimated`, at the last row's time, on `ranOn`. A real turn replaces it. A chat with /context numbers uses those and isn't marked estimated. KERNEL-842.

**A cache lasts an hour on a Claude plan and 5 minutes on a Claude API key or on Codex.** `coldReason` says `idle` past that. Claude Code caches for an hour on a plan and 5 minutes on a key. OpenAI keeps a prefix for 5 to 10 minutes of inactivity, so Codex takes the low end. Erring short only means Kernel treats a warm chat as cold. KERNEL-842.

**An account counts as another one when its email changed, and two accounts count as one once a move between them proved it.** `coldReason` compares the email the last turn ran with against the account's email now, ignoring case, so a CLI login changed in a terminal reads as `account`. After a move turn whose first call read more than half the chat from the cache, Kernel saves the pair in store meta (`sharedCaches`, per provider) and `coldReason` treats it as the same account from then on. KERNEL-842.

**A move onto a Claude API key is priced at the model's input price times 1.25, the cache write rate.** Claude Code writes the history to the cache as it reads it, so the first turn after a move pays the write rate on the whole chat. `MODELS` carries each model's window and input price. Codex gets tokens and no price, since Kernel has no price list for its models. KERNEL-842.

**The note about a move comes after the move turn, with what it read.** It replaces "Now on Personal" at the turn's start (KERNEL-568) with "Moved to Personal and re-read 310k tokens" after its result row, or "and read this chat from the cache" when the cache came along. The limit reason stays in brackets. A move turn that reported no numbers says "Moved to Personal". A chat that moved twice before a turn ended counts from the account it left first. Amends KERNEL-568. KERNEL-842.
