**The right panel is a top pane and a bottom pane, split 2/3 and 1/3, and the bottom keeps one size in every chat.** The size is a fraction of the panel below the PR band, 1/3 until it is dragged, saved as `kernel.bottomPanelRatio`. It isn't a height in px, so the split keeps its proportion in any window and switching chats doesn't move it. The top keeps at least 160px and the bottom at least its tab bar plus 120px, so a short window keeps both panes. The hairline between the panes is the handle. Drag it, use the arrow keys, Home and End, or press Enter to reset. It lights with the sidebar's edge glow turned horizontal (KERNEL-419). KERNEL-513.

**Collapsed or open is saved apart for Kernel's chats and for teammate workspaces.** Kernel's chats start collapsed because PRs is what you read there. Teammate workspaces start open because Run and Setup are what you reach for. Each kind has its own flag, `kernel.bottomCollapsed.lead` and `kernel.bottomCollapsed.teammate`, so collapsing in one leaves the other alone. The chevron left of Setup and ⌘J toggle it, and pressing a tab opens it on that tab. With the right panel hidden, ⌘J brings the panel back with the bottom open, so the shortcut never changes something you can't see. A collapsed bar keeps the Run button. KERNEL-513.

**A chat waiting on setup opens the bottom on Setup and leaves the top alone.** Amends KERNEL-430, which folded the files pane to its header so the log could take the height. The bottom pane now has its own room, so `setupFolds`, the `opened` state in `RightPanel` and `data-tall` are gone. Opening the bottom for setup is not saved. When setup ends, the state the user last chose comes back, and a collapse made during setup counts as that choice. A new chat with Kernel skips the setup wait (KERNEL-490), so it opens on PRs with nothing folded and nothing jumps when setup ends. KERNEL-513.
