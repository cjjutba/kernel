**A chat compacts against its model's own context window, and the context ring reads against that window. Amends KERNEL-226.** KERNEL-226 set `CLAUDE_CODE_AUTO_COMPACT_WINDOW=200000` on every Kernel session, so a chat on Opus 5.5 compacted near 167k and the ring read "151k of 200k tokens" on a 1M model. The maintainer wants the full window on a 1M model and a ring that shows it. `sessionEnv` no longer sets the variable, so Claude Code uses the model's window: a 1M model compacts near 967k and a 200k model near 167k, as before. `getContextUsage` reports that window as `maxTokens`, and the ring and popover show that number. The variable still works when the Mac's own environment sets it, and a project's `.env` still can't set it (KERNEL-247). The cost is plan usage. A long chat on a 1M model now sends up to five times the context per turn before it compacts, and Compact now in the popover is the way to free it early. The cap never shipped, so this change deletes its release note. KERNEL-334's amber at 75% now comes well before a compact on a 1M model, which compacts near 97%. It still comes before a compact on a 200k model.
