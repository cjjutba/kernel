**Editing a setting that already exists saves without a Save button.** The setup and archive scripts on a project's Scripts page, the PR instructions sheet and an account's name had Save and Cancel, while every page said "Changes save as you make them." (KERNEL-721). They now save like the other text fields: when the field loses focus, on Cmd+Enter for a script, or when the page or sheet closes with text still in it, with the Saving and Saved note beside them. Escape puts the saved text back. A script that is half written when focus leaves is saved as it is, since setup and archive only reach workspaces made or archived later. Dialogs that add something new (a run script, a variable, a preview URL, a terminal preset) keep Add or Save, so a half-filled item never shows in the list, and an agent's Save changes stays because it asks whether to save for you or open a pull request.
