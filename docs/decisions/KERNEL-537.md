**A room's `unlisted_tools` defaults to asking, so an agent's call to an MCP server its file doesn't list asks you instead of failing.** The `[agents]` table promised `ask` when unset, but nothing read it and every such call was refused. Now the call shows an approval card in every mode, and Always allow on it saves the room's tool rule, which lets the next call through. `unlisted_tools = "hide"` keeps the old refusal, and a server `disallowedTools` names is refused either way. `[agents.<id>] allow` was never read either: its servers now count as named on the agent's tools line, for Claude and Codex. **Block TaskCompleted without test output sends a task back once.** The gate can only see the commands that reach the session's own hooks, and a teammate's may not, so blocking every try could leave a teammate unable to finish. A second try at the same task goes through. Keep idle teammates working sends a teammate back at most three times in a row while no task finishes, for the same reason: tasks waiting on other tasks would otherwise loop. Both gates apply to Kernel's own sessions, not to outside sessions that report through the installed hooks. KERNEL-537
