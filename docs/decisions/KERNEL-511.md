**A chat with Kernel's Shared tab lists its own files and its teammates' files, not the whole room. Amends the room-wide rule behind `sharedHere` (D-104).** The Lead's workspace used to list every file shared in the room, because a room had one chat with Kernel and the Lead heard about all of them. Since KERNEL-405 each chat is its own workspace, so every chat's tab showed the other chats' files. A Lead chat workspace now lists files shared in itself plus files shared in any workspace with the same `threadId`, the teammates that chat handed work to. `threadId` is kept after the chat's tab closes (KERNEL-337), so those teammates stay listed. The Lead workspace from before KERNEL-405 has no `threadId` and keeps the room-wide list, and a teammate workspace keeps its own files only. The tab's count and whether it shows come from the same function. ⌘K search is untouched and still finds every shared file in the room. KERNEL-511.
