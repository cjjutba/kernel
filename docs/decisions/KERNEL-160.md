**Issues is a screen under Inbox, with a status shape per state and the status in words in each group header.** The sidebar reads Search, Home, Inbox, Issues, History, and Cmd+K lists Issues. The screen is a 400px list of the user's open Linear issues (`linear.issues`) and the selected issue on the right (`linear.issue`), with Plan with Rowan, New chat and Open in Linear under it. Mine is the default, and an All pill, Team, Project, Cycle and a search narrow the list. Mine, All and the three selects persist in `kernel.issuesFilter`; the search text does not, since a leftover word would hide issues on the next launch with nothing saying why. Project and Cycle start on All, because a backlog issue has no cycle and a default of the current cycle would hide it. Groups follow the state name in workflow order: triage first, as Linear shows it and IssuesWorking.png draws it, then started, unstarted and backlog, each by the state's position. Inside a group the order is priority (urgent first, no priority last), then most recently updated. That differs from the order the PNGs draw in places: in Todo they put an urgent issue last. Each group header carries the state's shape and its name, and the shapes are monochrome (dashed for backlog, a half fill for in progress, an arrow for triage). A priority is three bars lit by level, an outlined square for urgent, three dashes for none, and urgent is not colored. Open issues only, so there are no Done or Canceled groups. A row shows the agent and PR state of a workspace started from the issue ("Kai · PR open") in place of its age, and in All the assignee's initials. The workspaces come from `source.kind === 'issue'` with the issue's key, and archived ones are left out. Every state of the workspace comes from its PR and from a running chat, never a timer. The room picker defaults to the room whose Linear team is the issue's team, else the room last opened. With no room linked to the team, Plan with Rowan and New chat stay enabled, and "Link KERNEL to Client A" saves the room's Linear team with `settings.setRoom`. Linking only sets the default room. The second button is New chat and not "Start workspace", because the New chat modal sends the prompt to the room's Lead (D-131): the issue goes in as a chip and the Lead plans and hands off like any other brief. Plan with Rowan is the same send with plan mode on, through `linear.plan` (D-140). Not connected shows Connect Linear with a button to Settings, Integrations. A rejected token or an unreachable Linear shows a neutral failure banner with Try again, and so does being offline. Data is read when the screen opens, when the window gets focus, when the connection comes back, after Plan with Rowan and on Refresh. Nothing polls. KERNEL-160.
