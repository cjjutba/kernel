**Comparing with another branch counts from the merge base, as the default does.** The `branch` target diffs the worktree against `git merge-base HEAD <ref>`, which is what `git diff --merge-base <ref>` gives, not against the branch's tip. Against the tip, every commit that landed on that branch after the workspace started would show up as a change the workspace made, reversed. With the merge base, picking the base branch lists what the default lists, and picking another branch lists what the workspace has that the other branch doesn't. Uncommitted and untracked files count, as they do for the default. Two branches with no shared history diff against the branch itself. KERNEL-516

**One commit diffs against its first parent.** A merge commit such as "Merge origin/main into the branch" shows what the merge brought onto the branch, not a combined diff. A root commit diffs against the empty tree, so every file in it is added. KERNEL-516

**Only the default target saves the workspace's totals.** `workspaces.changes` with no target, or `base`, saves `stat` and pushes the workspace when it changes, as before. The other targets save nothing and push nothing, so the +412 -38 in the sidebar and on Home stays the work against the base whatever the Changes list is showing. KERNEL-516

**The commit list counts from the same place as the default target.** A worktree workspace lists `git log <baseRef>..HEAD`. A current-branch workspace lists the commits since its baseline, since those are the ones its agent made. KERNEL-516

**The new targets list a rename as one row, and the default still doesn't.** The branch, uncommitted and commit targets read `git diff -z`. They list a rename on its new path with `from` set to the old one, and a file diff passes both paths so git prints a rename rather than a new file. The default target keeps `changedFiles` as it was, which lists a rename under a path like `src/old.ts => src/new.ts` with status M. The brief asked for the default's results to stay exactly as they were, so switching it over is left for its own change. KERNEL-516
