**An agent is edited inside Settings, and the app has its own Agents page.** Settings, Agents lists the personal and plugin agents that join every room, from `agents.listGlobal` and its `globalAgents` push, so it works with no room. Edit on that page or on a room's Agents page opens the editor as a Settings sub-page whose Back link returns to the list it came from, and the old profile's status, workspace and recent work stay out of it. The editor fields moved to `screens/agent/AgentEditor.tsx`, which the old profile still uses until the Team screen is removed. A room's repo agent asks who gets a save (AgentProfileScope.png), a personal agent opened from the app's page saves through `agents.saveGlobal`, and a plugin's agent opens read only with no Save or Retire. There is no PNG for these pages: they are built from the Settings kit and AgentProfile.png's fields. KERNEL-641.
