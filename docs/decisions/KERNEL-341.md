**Each PR action has one ⌘⇧ key, and it works only while its button shows.** ⌘⇧P creates the PR or marks a draft ready, ⌘⇧M merges, ⌘⇧F sends the PR back to the agent to resolve conflicts, fix checks or address review, and ⌘⇧A archives a merged or closed workspace. The three fix states share F because each one hands the PR to the agent with an instruction file, and only one of them shows at a time. Ready for review reuses P because a draft is a PR you haven't finished creating, and Create PR and Ready for review never show together. ⌘⇧R is out: Kernel sets no app menu, so Electron's default menu binds it to Force Reload. Merge by key asks for no confirmation, the same as the click, and a key does nothing while a modal is open or while the PR is busy (Creating PR, Checks running, Resolving, Merging). Reopen, Continue and Create draft PR stay click-only. Reopen's natural letter is the Force Reload key, and Create draft PR already sits one click away in Create PR's menu. Hovering a keyed button shows its key in the tooltip. KERNEL-341.
