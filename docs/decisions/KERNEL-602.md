**Every scroll area draws the sidebar's thin scrollbar, and it fades.** Amends KERNEL-597. One block in `tokens.css` styles all scrollbars, vertical and horizontal: 6px, rounded, no track, `--line-4`, `::-webkit-scrollbar` rules only. `.tab-strip`, `.bd-filter` and `.tm-filter` keep `scrollbar-width: none`, which still hides theirs. `ui/scrollIdle.ts` replaces the per-list `useScrollIdle` hook. It adds one capture-phase `scroll` listener on the document, started from `main.tsx`, that sets `data-scrolling` on whatever scrolled and clears it a second after the last event, so a screen needs no code to get the thumb. The thumb is transparent until the area is hovered or has `data-scrolling`, then fades in over 150ms and out over 300ms. Chromium can't transition a scrollbar part, so the colour is a custom property registered with `@property` as a `<color>` (`--scroll-thumb`) and the thumb reads it. The registration has to say `inherits: true`. A scrollbar part takes its style from its scroller the way a child does, so a property that doesn't inherit reads as its initial value there and the thumb never shows (it stayed transparent with `inherits: false`). Every element declares its own `--scroll-thumb: transparent` so a scroller never takes its parent's value, and the `transition` and the hover rule are wrapped in `:where()` so they have no specificity. An element's own `transition` replaces the fade, so a scroller that declares one must list `--scroll-thumb` too (none does today). `prefers-reduced-motion` and Settings, Appearance, Reduce motion turn the fade off and the thumb snaps. A custom scrollbar takes 6px of layout width where the content overflows, which the old overlay scrollbars did not, so an overflowing page is 6px narrower. The sidebar holds a stable gutter and pads itself back (KERNEL-597) to avoid that. Page scrollers don't, so a centred column moves 3px left when its page starts to scroll. Two lists that sat in from a modal's edge because of padding, `.cr-list` (Connect repo, Open folder) and `.ts-list` (Trust scripts), get the sidebar's bleed: a negative right margin, the padding less 6px, and a held gutter, so the thumb is on the modal's edge and rows stay where they were. The right panel's resize handle reached 3px into the chat column and covered half of the chat's thumb, so it now starts on the panel's own border (`left: -1px` in `components/resize.css`) with its glow where it was. KERNEL-602.
