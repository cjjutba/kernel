**The guard hook and the project deny rules are removed.** Replaces D-023 and the KERNEL-971 live-test allow list. Agents run with bypass permissions, and a deny rule or a hook denial stops the work with no prompt, so CJ has no way to approve the command. Ivy got stuck this way on `KERNEL_LIVE`. `.claude/hooks/guard.mjs`, its test and the `permissions.deny` list in `.claude/settings.json` are gone. Nothing in the repo blocks these any more: edits outside the repo, `rm -r` outside the repo, `gh repo delete` and `gh repo edit`, edits to `~/.claude/settings.json`, and any `KERNEL_LIVE` run. `main` stays protected by GitHub branch protection: no force pushes, and a PR with review and the Release note, Test and CLA checks. That is the only remaining protection, and it is intended. Kernel's in-app Never allow and Always ask lists (D-016) are user settings and stay. D-023, D-095, D-111 and KERNEL-971 stay as history.
