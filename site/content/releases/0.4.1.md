## New

- Usage for Claude Code and Codex now shows in the footer all the time, with a Detailed and Compact popover to switch accounts. (#640)

## Improved

- Removed Ask Kernel and its history from the footer. Questions for Kernel go in Kernel's chat, which the sidebar row, Cmd+K and Cmd+Shift+L still open. (#634)
- Clicking a Read image row in a chat opens the image in a tab beside the chat, and hovering the row shows a preview. (#635)
- Bypass permissions no longer asks before an agent uses an MCP server its agent file doesn't list. (#636)
- Settings, Permissions and the Bypass permissions confirmation no longer list an agent's tools line among what Bypass stops for. (#637)
- Usage numbers refresh about a minute after an agent finishes a turn, without opening the Usage popover. (#639)
- Links in run, setup and terminal output open in your browser when you click them. (#643)
- With plan mode off, Kernel hands off work or files issues only after a clear yes, and answers a reply that also asks questions before asking again. (#644)
- The usage footer spans the whole window with 5-hour, weekly and Fable numbers and a refresh button, the usage popover and account menu are shorter, and a new Help button at the bottom right opens What's new, Keyboard shortcuts and Report a problem. (#645)

## Fixed

- Fixed a hovered choice on a question card looking more selected than the one you picked. (#641)
