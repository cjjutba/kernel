---
version: 0.4.0
date: 2026-10-13
title: Reviews, accounts and a calmer window
intro: Kernel can review each pull request on its own and, if you turn it on, merge it once the reviews approve. You can add API key accounts, switch accounts when one hits its limit, and see every account's usage. Chats gain next-message suggestions, a permission mode picker and a list of the files each reply changed, and the sidebar, scrollbars and icons are redone.
---

## New

- Chats with a reply you haven't opened yet show a bold title in the sidebar and the tab row. (#450)
- A button appears at the bottom of a chat once you scroll up, and takes you back to the newest message. (#464)
- After a turn, the message box shows Claude's guess at your next message, and Tab or the right arrow key puts it in the box. (#468)
- Settings, Scripts sets how long a setup or archive script may run before Kernel stops it. (#477)
- The Changes tab has a menu to compare a workspace with another branch, with only its uncommitted changes, or with a single commit, and the diffs it opens follow your choice. (#480)
- Team and Room setup warn when an agent's file pins a model that no provider you're signed in to offers. (#486)
- Settings, Providers can add an Anthropic or OpenAI API key as an account and switch agents to it. (#487)
- Kernel reviews each pull request by itself once its checks pass, with a code review on every pull request and security and UX reviews a room can turn on for the files it chooses. (#489)
- Kernel can merge a pull request by itself once every required review approves its latest commit and its checks pass, a personal setting that stays off until you turn it on and that a team's shared settings can't turn on. (#508)
- Pick a chat's permission mode from the composer, or cycle it with Shift+Tab. (#509)
- Replies in Claude and Codex chats now show a Changed row listing the files the turn added, edited or deleted, with lines added and removed. (#510)
- A clock next to Ask Kernel in the footer lists the questions you asked before, and opens the chat with each answer. (#521)
- Settings, Pull requests has a Merge automatically switch, off by default and only on your Mac, with a size limit and the paths you always review yourself. (#524)
- Settings, a room, Reviews lets the whole team choose which reviews run on each pull request, which agent runs them and how many review rounds go by before it comes to you. (#524)
- Settings, a room, Reviews has an Always review yourself list of paths, saved in settings.toml so everyone on the repo gets it. (#526)
- Zoom a shared image from 25% to 400% with the buttons beside Comment, pinch, ⌘ scroll or ⌘+ and ⌘-, and drag to pan. (#530)
- Chats have a rail on the right edge with a mark for each message you sent, and hovering it lists them so you can jump back to one. (#531)
- Kernel can switch to another Claude or ChatGPT account when one hits its usage limit, turned on in Settings, Providers, and the chat notes where the account changed. (#536)
- A banner warns before an account reaches its usage limit and offers to switch to one with room. (#540)
- Back and Forward buttons at the top of the sidebar, and next to Show sidebar when the sidebar is hidden, so you can step through the places you visited without the keyboard. (#580)
- Settings, Agents lists your personal and plugin agents without a room, and Edit on any Agents page opens the agent's editor inside Settings. (#582)
- Kernel can pass screenshots you attach in its chat on to a teammate with a hand-off or a follow-up, and they show in the teammate's chat. (#599)
- Kernel can pass an image one teammate shared to another teammate, and the receiver keeps the version Kernel sent even after a newer one is shared. (#603)
- An empty room can copy another room's agents from Settings, Agents with Copy from another room. (#609)
- New agent in Settings, Agents works before you add a room. (#613)
- New chat with Kernel shows how many agents are working, what waits on you and which pull requests are ready to merge, and lists the next issues from Linear or GitHub with a Plan button. (#614)
- New chat with Kernel can branch the chat's worktree from any branch on the remote, not only the default one. (#614)
- Codex shows the OpenAI logo next to its models, accounts and settings, as Claude shows its own. (#620)
- Settings, Models and effort lets you choose where each role's chats compact. (#623)
