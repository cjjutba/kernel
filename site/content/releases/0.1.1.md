## New

- With Symlink node_modules on in Settings, Files, new and restored workspaces use the main checkout's node_modules, so agents can start without installing packages again. (#54)
- The New workspace box takes pasted screenshots, long pastes and dropped files, like the chat box in a workspace. (#55)
- Buttons at the top of the window hide and show the sidebar and the right panel, as do ⌘B, ⌘⌥B, and ⌘Backslash for both at once. (#56)
- Hovering an attached image in any message box or sent message shows the image, and clicking it opens the image in its own tab next to your chats. (#57)
- The Lead hears when a teammate finishes or a pull request changes, so it can ask for a review or report back without you prompting it, with a switch in Settings, Models and effort. (#63)
- Workspaces in the sidebar show their state as an icon: a question mark when one needs you, a spinner while it works, and its pull request in green when ready to merge, red for conflicts or failed checks, and purple once merged. (#64)
- Open the Lead's chat from the sidebar, the command palette, Ask Rowan or ⌘⇧L, even before the first brief. (#65)
- New workspaces can start in plan mode, with "Start new workspaces in plan mode" in Settings, Models and effort. (#67)
- Clicking a room in the sidebar collapses or expands it, and hovering a room shows its arrow and its menu button. (#71)
- Hovering a workspace in the sidebar shows an archive button, so you can archive it without opening it. (#73)
- The / menu in the message box lists Claude Code's own commands, such as /clear, /compact and /context, next to your skills. (#75)
- Clicking the plan at the bottom of the sidebar shows your account and how much of the 5-hour, weekly and per-model limits you have used, and buttons beside it open What's new and Settings. (#76)
- Hovering a workspace or the Lead in the sidebar shows a card with its status in color, what the agent did last, the branch and the diff totals. (#77)
- You can ask the Lead to archive finished workspaces, and it skips any with an agent still working, an open pull request or uncommitted changes. (#84)
- A new chat takes a short title from its first message instead of staying "New chat". (#85)
- Hovering a chat tab shows a close button, and closing a chat while its agent is still working asks before stopping it. (#85)
- Pasted text shows its contents when you hover it and opens in its own tab when you click it, like pasted images. (#88)
- The + menu in the message box can link a Linear or GitHub issue, or other workspaces in the room, so the agent gets them as context. (#91)
- Kernel saves each plan from plan mode as a file in its workspace, so a later chat can attach it with @ and build from it without planning again. (#91)
- You can drag the sidebar's right edge to make it wider or narrower, and Kernel remembers the width. (#114)
- You can drag the workspace right panel's left edge to make it wider or narrower, and Kernel remembers the width. (#119)
- Rowan can hand a pull request to the team's reviewer, who reviews it on that branch and reports approved or blockers back to Rowan. (#127)
- Press ⌘1 to ⌘9 to jump to the room's Team, its Lead chat and its workspaces in sidebar order, and hold ⌘ to see each row's number. (#141)

## Improved

- What's new shows each change in a release on its own line. (#47)
- Attachments sit inline in your message where you pasted or added them, and your text wraps around them. (#55)
- Agents stopped mid-task by a usage limit pick the task up again on their own once the limit resets, or as soon as you switch them to another model. (#62)
- Rooms paused by a usage limit stay paused when Kernel restarts, and resume on their own once the limit resets. (#62)
- Send now on a queued message sends it even while a usage limit pauses the room, and the room resumes if the limit turns out to be gone. (#62)
- The pull request buttons sit at the top of the right panel, which now runs the full height of the workspace, and the Changes tab shows how many files and lines changed in total. (#64)
- Each room in the sidebar shows its New workspace button without hovering. (#71)
- The Setup tab says when a room has no setup script, and its Add setup script button opens Settings, Scripts. (#72)
- The window can now shrink to half a laptop screen, and the sidebar and right panel fold away when it gets narrow instead of squeezing the chat. (#74)
- The footer no longer shows the hook server's address while hooks are working, and still says when they are down. (#76)
- Icon buttons show a tooltip with their name, and their shortcut when they have one, when you hover them or reach them with Tab. (#76)
- Sidebar and Settings rows have a small gap between them, so a hovered row no longer runs into the selected one. (#77)
- The Lead's row in the sidebar shows what the Lead is doing: a spinner while it works, a question mark when it needs you, and a warning when it is blocked or offline. (#82)
- Buttons that take a moment, like Archive, Merge or Approve, show a spinner and say what they are doing until they finish, and can't be pressed twice. (#83)
- The open chat tab shows a pen instead of a menu arrow, and the tab's menu opens when you right-click it. (#85)
- Attachments in a message box sit inside the text like words, so you can type before, between or after them and remove one with Backspace. (#87)
- Plan mode shows as a hatched message box instead of a "Plan mode" button, and the + menu turns it on or off. (#91)
- The model picker shows each model with the effort you last used it at, picks effort from a list, and switches models with ⌃⌘1 to ⌃⌘4 even when it is closed. (#91)
- A plan from plan mode shows in the chat as a formatted document, with Copy and Approve on the message box, and anything you type there goes back to the agent as changes to the plan. (#91)
- Chat tabs show a spinner while the agent works and a question mark when it needs you, and every tab icon is the same size. (#93)
- Chats and new workspaces start right away instead of waiting in "Queued", because Agents working at once in Settings, Models now defaults to No limit and never counts the Lead's chats. (#96)
- The message box shows how full the context is as a ring next to the plus button; hover for the token counts, or click for a breakdown and a Compact now button. (#101)
- A chat waiting on a plan shows a clipboard icon instead of a question mark. (#104)
- Rooms open to Rowan's chat now that the floor and the Board are hidden, and two agents editing the same file show up in the Inbox. (#106)
- The sidebar no longer shows the Try section; connect a repo or open a folder from the menu next to Your rooms. (#108)
- Check hooks and Settings, Hooks say that hooks report to Kernel instead of to "the office". (#111)
- Rowan no longer tells you that a new agent joins the floor or that status updates show there, now that the floor is hidden. (#111)
- Rowan gets clearer teammate updates: one entry per teammate, the full reply, and plain wording for pull request status. (#115)
- Rowan only starts a turn for a teammate update when something needs attention, such as failed checks, a review or a question. (#116)
- Rowan answers a teammate's question from the plan or asks you, calls teammates by name, and replies to updates in a line or two. (#126)
- Teammate updates in Rowan's chat show as a Team update card with one row per teammate and an Open link, instead of looking like your message. (#130)
- When Kernel archives a review you are looking at because the pull request it reviewed merged or closed, you land in the Lead's chat instead of History. (#131)
- A file's diff opens in its own tab, so the chat stays where you left it. (#136)
