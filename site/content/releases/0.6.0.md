version: 0.6.0
date: 2026-10-17
title: Work, pull requests and chats that pick up where you left off
intro: Issues and pull requests share one Work page, and its Pull requests tab lists open pull requests across every project, with Merge on the ones that are ready. Chats, panels and lists reopen where you left them after a restart, and a file path an agent mentions opens in a tab. You can attach any file to a message, and the Run button always sits in the bottom panel. Adding a project takes seconds: clone a GitHub repo, open a folder or start from scratch, and it opens straight into New chat. Rooms are now called projects, both themes use neutral greys, and frontend and backend agents can run on different models.
---

## New

- A Pull requests page in the sidebar lists open pull requests across every project with their checks, review and conflicts, offers Merge on the ready ones, and shows recently merged ones under Merged. (#860)
- Issues and Pull requests are now one entry in the sidebar, Work, with a tab for each and a project picker that includes All projects on Pull requests. Press 1 or 2 to switch tabs. (#888)
- The bottom bar has a History button, just left of Help, that opens History for all projects. (#920)
- You can attach any file to a message, up to 50 MB each, and the chip shows its type and size. (#929)
- The Run button is always in a workspace's bottom panel, with a menu to start any run script, run them all or open the project's scripts. (#930)
- Chats reopen where you left them after a restart, and Scroll to bottom shows how many new messages arrived while you were reading higher up. (#942)
- Work, Issues has a Linear | GitHub switch in its header for projects that have both, and remembers the choice per project. (#958)
- File paths that agents mention in chat open the file in a tab when you click them. (#1003)
- Command Shift H switches a chat with Kernel between Hand off and Build here. (#1022)
