## New

- **Claude Code in terminal tabs.** Terminal tabs now run Claude Code connected to Kernel's tools, pick up the same session after Kernel restarts, and can be turned off in Settings, Terminal. (#1038)
- A Lead workspace's new tab menu offers a Lead terminal, terminal tabs show when they are working or need you, and Settings, Big terminal has a switch to connect terminals to Kernel. (#1047)
- A Lead running in a terminal tab now hears what its teammates did on its next message or when it checks, without Kernel typing into the terminal. (#1048)
- A terminal tab for a Lead or teammate can switch between the Terminal and a read-only Transcript of its session, and it remembers the choice for each tab. (#1050)
- A teammate can now run in a terminal tab instead of Kernel, chosen per hand-off, per project or for the whole app in Settings, Terminal. (#1057)
- Settings, Pull requests can let pull requests merge by themselves on green checks without a review. (#1059)
- Settings, Big terminal and each project's Agents page let you choose whether teammates run in Kernel, in a terminal, or the same as the Lead, and a teammate running in a terminal says so. (#1060)
- A teammate's question to a terminal Lead can be answered from the Inbox, a Lead terminal tab shows how many team updates wait, closing a working terminal asks first, and a teammate running in a terminal is marked in the sidebar. (#1074)
- Switching a chat with Kernel to Build here gives it a worktree, or your current branch when Settings, Git and worktrees says so, the first time it builds. (#1117)
- New teammates start on Codex when every Claude account is at its limit, and on Claude when every Codex account is, using the model and effort set for that role in Settings, Models and effort. (#1124)

## Improved

- Terminal chats of a Lead or teammate now show working and idle, take their title from the session, and let the Lead act on what you typed there. (#1045)
- Teammates and reviews start right away while the setup script runs in the background, and a failed setup no longer stops them. (#1051)

- A teammate's chat shows its work while setup runs, and a failed setup no longer blocks it, unless Wait for setup before agents start is on in Settings. (#1066)
- The first message in a new chat starts sooner, because its workspace is prepared while you write it. (#1067)
- The chat transcript is quieter: a single tool call shows as its own row, denied calls are named once, runs of grey notes fold into one line, and only the latest turn shows its time and actions until you hover an earlier one. (#1069)
- A chat that moves to another account with a summary shows one note instead of three, and no longer says it re-read 0 tokens. (#1070)
- A new chat gets its name in the sidebar as soon as you send the first message. (#1071)
- New projects offer starter agents named Christian, Sean, Teng and Artkin. (#1072)
- The + menu offers Chat and Terminal, and terminal tabs no longer show teammate or Lead terminal controls. (#1081)
- Messages you or the Lead send no longer wait while other chats move to a new account. (#1082)
- Terminal tabs open as plain terminals again, and every teammate runs as a chat in Kernel. (#1083)
- The message queue says when a message waits for other chats to move to a new account. (#1085)
- Code blocks show a copy icon that turns into a check, in place of the Copy button. (#1086)
- Every copy button is now a clipboard icon that turns into a check after copying. (#1087)
- A chat with Kernel in Build here shows only Create PR above its changes, without a Link issue button beside it. (#1096)
- Unread chats in the sidebar keep the same icon weight as read ones, and the small buttons in the footer and the chat hover card use the smaller corner radius. (#1100)
- Inbox, Issues, Pull requests, History and Projects now share one row height and rounded rows without dividers. (#1104)
- Image chips are now monochrome, and the composer pickers and buttons share the same radius, edge and button sizes. (#1106)
- Buttons in the pull request band and the shared file view now share the stock button radius, hover and disabled looks. (#1107)

- Run, Open in, Create PR, Open and Settings' Open settings file buttons now share one joined split button design. (#1110)
- Links, focus rings, script field borders and list row hovers look the same on every screen, in both themes. (#1113)
- Keyboard focus rings, text colors and small control sizes are now consistent across menus, the composer, Projects and the pull request lists. (#1114)
- A new chat with Kernel in Hand off starts right away, without making a worktree or running the setup script. (#1116)
- Settings, Git and worktrees says which settings apply to chats with Kernel, and a chat shows when it is waiting for its turn to end or making its worktree. (#1118)
- Chips in the composer and on sent messages show a colored icon for their kind, such as images, pasted text, files, issues and pull requests. (#1119)
- Chats no longer show setup steps after a project's first chat, and the Build here switch responds right away. (#1122)
