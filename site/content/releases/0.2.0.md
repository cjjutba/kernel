---
version: 0.2.0
date: 2026-10-11
title: From issue to merge
intro: Kernel now takes work from a Linear issue to the merge, with every open pull request listed in Rowan's chat and a Merge button on the ready ones. A repo that brings its own agents works right away, and agents can share pages and images for you to comment on.
---

## New

- Starting a workspace on a Linear issue moves the issue to In Progress, and Rowan links the workspaces it hands off to the issues they build. (#150)
- When an update has downloaded, a card in the bottom right says so, with See changes to read what's new and Restart to install it. (#153)
- Choose a room's Linear team in Settings, and see the issue key next to the branch on a workspace started from an issue. (#157)
- Issues in the sidebar lists your open Linear issues, and Plan with Rowan or New chat starts work on the one you select. (#160)
- Chats in the sidebar fold to hide the workspaces they started, and rows under a room sit closer to the left edge. (#178)
- Go back and forward between screens and chats with ⌘[ and ⌘], or the back and forward buttons on a mouse. (#180)
- Files to copy in a room's settings accepts patterns like `.env*`. (#182)
- Rowan can hand off a task that waits for another pull request, and Kernel starts it when that pull request merges. (#188)
- Kernel reopens on the screen and chat you left, with unsent messages back in their boxes. Settings, General, Default home view can open Home or Inbox instead. (#200)
- A room can show its GitHub avatar or a picture you choose instead of its letter, in Settings, Room, General, and the picture appears in grayscale wherever the room is listed. (#211)
- A room's Scripts page lists named run scripts you can add, edit and remove, and the Run tab has a picker so each script starts, stops and shows its own output. (#212)
- A room's Scripts page in Settings has a Preview URLs list, and a workspace's Checks tab has an Open button that opens the first one in your browser, or the address a run script printed. (#226)
- Settings, Environment and each room's Environment page let you add, show, edit and delete the variables that chats, scripts and big terminal tabs get, and list a room's env files. (#228)
- Settings, Big terminal lets you pick what a new terminal tab runs and add your own commands, and the + menu in the tab strip lists every preset. (#229)
- History can delete archived workspaces one at a time or all at once, along with their branches, checkpoints and Claude Code transcripts. (#248)
- Agents can share an HTML page, image, PDF or Markdown file with you, which opens in a tab in Kernel, where HTML runs live without network access. (#253)
- The PR header's buttons have shortcuts: ⌘⇧M merges, ⌘⇧F sends the PR back to the agent to fix, ⌘⇧P marks a draft ready and ⌘⇧A archives a merged or closed workspace. (#259)
- A workspace waiting on a repo's scripts now shows a banner with a Review button, and a dialog lists exactly what will run so you can trust it or leave it held. (#262)
- The menu under a reply can fork the chat into a new workspace, with its own branch, the same files and the conversation up to that reply. (#275)
- Comment on a shared page or image, and the agent that shared it gets your note with a picture of the spot. (#276)
- The sidebar shows one row per chat with Rowan, the tab row shows that chat's tabs, and New tab adds a tab to the chat you are in. (#277)
- Search lists the room's chats with their tab counts, and Ask Rowan answers in a new tab when you ask from inside a chat. (#283)
- Help, Copy diagnostics copies Kernel's versions and its recent log, with tokens and your home folder hidden, so you can paste them into a bug report. (#290)
- A room's Git page in Settings can turn Archive on merge and Delete branch on archive on or off for that room. (#301)
- A workspace that other chats wait for shows who is waiting above the message box, and clicking a name opens that chat's workspace. (#310)
- Merge a pull request that's ready from its row in a Team update in Rowan's chat. (#312)
- You can ask Rowan to merge pull requests that are ready, once you turn it on in Settings, Pull requests. (#313)
- You can turn off automatic review in Settings, Pull requests, so pull requests that pass checks come to you ready to merge. (#320)
- The right panel in Rowan's chat lists every open pull request in the room, and you can merge the ready ones from there. (#321)
- The Changes tab can show changed files as a folder tree. (#332)
- A repo that brings its own agents works right away: Kernel's own Rowan leads and Theo reviews until you pick your own in Settings, Agents, and neither adds a file to the repo. (#336)
- Room setup shows the team a repo brought with it, so you can pick who leads and who reviews before the room opens. (#336)
- Settings, Agents picks a room's Lead and reviewer and which agents take tasks, and saves the choice in the repo for everyone. (#336)
- Team adds Kai, Noor or Ivy to a team that already has agents, and Customize copies Kernel's own Rowan or Theo into the repo so you can edit them. (#336)
- Kernel can send anonymous usage data once you say yes, and Settings, Privacy lists exactly what was sent and what never leaves your Mac. (#336)

## Improved

- Agent steps in a chat show which model the subagent runs on and what it was asked to do. (#149)
- The sidebar lists your open chats with Rowan under each room, with the workspaces each chat started nested under it, and Team now lives in the room's menu. (#152)
- When Kernel can't reach GitHub while starting a workspace, it now says so and shows how old its copy of main is. (#163)
- Chat names follow the conversation and settle as it goes on. (#165)
- Every step in a chat, thinking included, opens to show what the agent did. (#166)
- Back to app in Settings and switching between workspaces now return you to the chat and tabs you had open. (#167)
- ⌘N opens New chat, so you can brief Rowan from anywhere. (#172)
- Kernel backs up its data before an update changes it, asks you to update instead of opening data from a newer version, and stays smaller by clearing activity older than 30 days and shortening approvals settled more than a week ago. (#179)
- Notifications say how many questions an agent is asking, and every answer goes back with its question. (#184)
- Long chats and noisy run scripts no longer slow the workspace screen, and a chat stops scrolling back down while you read earlier messages. (#185)
- Branch names for new workspaces are short: the issue key and a few words of its title, starting with fix for bugs and feat otherwise. (#192)
- The pull request header shows each state with its own color and label, plan mode turns the composer blue, and team updates and Ask Rowan are simpler to read. (#193)
- Settings lists each room with its own pages (General, Git, Scripts, Files to copy, Instructions, Permissions, Agents, Skills and MCP), and each page reads and changes only that room. (#194)
- Chats left idle for 10 minutes stop their Claude Code process and MCP servers to free memory, and the next message picks the conversation up where it left off. (#197)
- When Linear marks an issue as blocked by another a teammate is building, Kernel tells the teammate once the blocking pull request merges. (#199)
- A queued message says what it is waiting for, such as a free agent slot or the room resuming. (#201)
- A teammate that has to wait for another pull request now tells Kernel, and Kernel picks it back up when that pull request merges. (#205)
- Archiving a workspace no longer waits for its folder to be deleted, so it leaves the sidebar at once. (#206)
- A room's Files to copy page lists the files a new worktree will get, with a Refresh button. (#208)
- Starter agents run only the tests their change touches, and leave the full suite to CI. (#214)
- A pull request note in a chat shows the PR's state icon, such as the purple icon once it merges. (#221)
- The context ring in the composer turns amber as a chat gets close to compacting and red when it is almost full. (#242)
- Closing the open chat tab now opens the tab to its right, like a browser, and the one to its left only when it was the last tab. (#249)
- The page behind a dialog is dimmed and blurred less, so it stays visible while the dialog is open. (#250)
- The message box is shorter and quieter, and in plan mode its blue glow rises slowly and breathes while it waits for you. (#251)
- Opening a chat or workspace from the sidebar, or with ⌘1 to ⌘9, puts the cursor in its message box. (#255)
- The model picker shows the official Claude logo in its orange next to each model. (#266)
- A plan's outcome in a chat, such as Plan approved, now has an icon and a rule after it, like a PR note. (#270)
- Icon buttons brighten when you hover them instead of showing a gray square behind the icon. (#271)
- The actions under a chat message are icons with a tooltip, and Copy turns into a check mark when it copies instead of showing a notice. (#271)
- The time under a finished reply now shares its line with Copy, Retry and a menu for forking the chat. (#275)
- ⌘1 to ⌘9 open the room's chats with Rowan in sidebar order and no longer count workspaces. (#280)
- An agent's questions show their headers as tabs you can jump between, and a Something else answer is typed inside its own row. (#285)
- Clicking the picture on a shared file opens it, like the Open button. (#291)
- A room with no chats opens on New chat with Rowan, and the chat appears in the sidebar when you send. (#295)
- A step in a chat (Thinking, a tool call, a message in the folded tool calls) now gets a soft fill when you hover it or tab to it, so it is easier to tell which line you are on. (#297)
- Reviews send a pull request back only for real problems, so fewer pull requests go through extra fix rounds. (#300)
- Archive on merge in Settings, Git now says it also archives review workspaces. (#303)
- Pasting up to 10 lines or 1,000 characters into a message box keeps the text in the box instead of turning it into a pasted text attachment. (#305)
- Rowan works in its own copy of the repo, so its chats no longer touch your main checkout. (#309)
- A chat or queued message waiting for other work to merge names each PR or issue it still waits for, and clicking one opens that workspace. (#310)
- A workspace waiting for you to trust the room's scripts now shows the needs-you icon in the sidebar, and so does a folded chat that hides it. (#315)
- Chats and workspaces in the sidebar no longer open a card when you hover over them. (#319)
- Each new chat with Rowan starts on the latest main. (#322)
- A failing check your repository doesn't require no longer marks a pull request as failed, and when GitHub's branch rules still hold a pull request, the header reads Open and Merge PR says why. (#324)
- A pull request's status now updates within seconds of a change on GitHub, and right away when you come back to Kernel. (#324)
- A workspace's right panel always opens on Changes, and the Lead's on PRs, instead of on whichever tab you picked in the last workspace. (#328)
- Copying a branch name or diagnostics no longer shows a toast, and Copy in Settings, Hooks says Copied on the button instead. (#329)
- Toasts slide in and out instead of popping up, keep to one line when they fit, and close when you swipe them right. (#329)
- A workspace waiting for you to trust its repo's scripts now counts as needing you on Home, in the Inbox and on its room's card. (#331)
- The All files tree moves with the arrow keys, puts a chain of single folders on one row, and collapses every folder with one button. (#332)
- Files show colored icons for their type wherever Kernel lists them, and changed files are colored by what changed, the way VS Code shows them. (#332)
- The footer says when Kernel has paused reading pull requests for GitHub's rate limit, and when it reads them again. (#335)
- A room's Git settings can list checks that never mark its pull requests as failed, for repositories whose branch rules require no checks. (#335)
- Rowan hears when GitHub blocks or unblocks a pull request that passed its checks, asks the agent to update a branch that fell behind, and the Inbox waits to say ready to merge until GitHub would merge it. (#335)
- Agents only use the tools their agent file lists, plus Kernel's own, so an agent marked read-only can no longer edit files. (#336)
- A repo's own agents learn to share mocks, screenshots and reports the way Kernel's starter agents do, and reviews block only on the rules in that repo's own CLAUDE.md or AGENTS.md. (#336)
- Only an agent marked lead: true, or with role: Lead, leads a room, so an agent whose description mentions leading no longer takes over Rowan's chats. (#336)
