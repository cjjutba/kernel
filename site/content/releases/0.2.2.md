## New

- Each chat with Rowan gets its own worktree and branch, runs the room's setup script before Rowan starts, and archives into History with the workspaces it started. (#343)
- A setup script can write variables to $KERNEL_ENV, and every agent, run script and terminal in that workspace gets them. (#343)
- When main changes in a way that would conflict with a teammate's unfinished work, Kernel tells the teammate to rebase before they open a pull request. (#348)
- The Lead's PRs tab can merge every ready pull request with Merge all, one at a time, and stops at the first one that can't merge. (#352)

## Improved

- Questions from Rowan show a short explanation under each answer, and long answers wrap onto more lines instead of squeezing into one row. (#341)
- The new chat window no longer shows a sending message next to the Create button. (#345)
- Workspaces warn before a usage limit and when a chat gets long. (#348)
- New installs get models, effort and limits that fit your Claude plan, and Kernel saves only the settings you change. (#348)
- Team updates and the PRs tab show each pull request's issue key and plain title, describe its review in the same words, and keep a merging pull request in place until it lands. (#352)
- The workspace header shows the task's title instead of its branch, hovering it shows the branch to copy, and the panel button stays in the top-right corner. (#355)
- Kernel now needs macOS 13 or later, since it moved to Electron 44 to keep getting security fixes, and Macs on macOS 12 aren't offered this update. (#357)
- An agent's chat says when its agent file lists an MCP server that isn't connected, and suggests the connected one. (#358)

## Fixed

- Fixed Kernel being unable to update itself when it could not start, so it now checks for a new version and offers to install it. (#342)
- Fixed a workspace whose folder was deleted outside Kernel still opening as ready. (#343)
- Fixed a restored workspace starting without running the room's setup script. (#343)
- Fixed new files showing "No changes to show" in the diff tab until the agent commits them. (#346)
- Fixed the pause near the limit and the weekly warning in Settings, Account doing nothing. (#348)
- Fixed review comments from people outside a repository reaching the agent when you press Address review. (#348)
- Fixed rules in Settings, Permissions missing quoted, aliased and reordered forms of risky commands. (#348)
- Fixed a new room running a repository's install scripts before you trust them. (#348)
- Fixed images in the Changes and All files tabs opening as an empty diff instead of showing the picture. (#350)
- Fixed several Merge buttons spinning at once when only one pull request was merging. (#352)
- Fixed Rowan thinking a teammate had started when its workspace was waiting for you to trust the room's scripts. (#353)
- Fixed checkpoints of workspaces archived over 30 days ago staying in the repo's .git forever. (#354)
- Fixed pull requests not working for repositories with a dot in their name. (#356)
- Fixed Kernel holding every message as if offline on networks that go through a proxy. (#356)
- Fixed New room committing everything in a folder it set up as a new repository. (#356)
- Fixed two rooms with the same name sharing a worktree folder. (#356)
- Fixed saving in Settings erasing a repository's Kernel settings file that had a typo in it. (#356)
