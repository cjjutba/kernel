## Home

Home shows what needs you across every room: requests to answer, plans to review, questions, and pull requests ready to merge. Each item opens where it happened. Settings, General can open Home or the Inbox at launch instead of where you left off.

## Inbox

The Inbox lists everything waiting on a decision:

- a command an agent wants to run
- a plan to review
- a question from Kernel or an agent
- a pull request that's ready to merge
- a workspace waiting for you to trust its repo's scripts

Answer each one right there. The sidebar shows how many are waiting. The Inbox lists only what you can still act on, and settled rows go after a week.

## History

History keeps archived workspaces and chats. Restore one, or delete archived workspaces along with their branches, checkpoints and transcripts.

## Notifications

Kernel sends macOS notifications for what you choose in Settings, Notifications:

| Notification | When |
| --- | --- |
| Permission requests | An agent asks before running something |
| Plan ready for review | Kernel has a plan for you |
| Pull request ready to merge | Checks passed and reviews approved |
| Failed checks | A pull request's checks failed |
| Workspace finished | An agent finished its task |
| Agent idle | An agent has been idle for a while |

The same page sets the sound and quiet hours.
