---
title: Shared files and comments
description: Agents can show you pages, images, PDFs and Markdown, and your comments go straight back to them.
---

An agent can share an HTML page, an image, a PDF or a Markdown file with you, such as a mock, a screenshot or a report. It opens in a tab next to your chats, and the workspace's **Shared** tab lists everything shared so far.

## Viewing

- **Pages run live.** An HTML page runs in the tab without network access, at Desktop, Tablet or Phone width.
- **Versions.** Each time the agent shares the file again, it gets a new version. The Versions menu lists them with their notes, and the tab follows the newest unless you pick an older one.
- **Images zoom** from 25% to 400% with the buttons beside Comment, a pinch, ⌘ scroll, or ⌘+ and ⌘-. Drag to pan.
- **Show in Finder** reveals the file. Shared files are kept in the workspace under `.kernel/shared`.

## Commenting

1. Press **Comment** on a page or an image.
2. Click the spot you mean. On a page, Kernel outlines the element under the pointer.
3. Type your note and press Send, or Return.

The agent that shared the file gets your note with a picture of the spot, the file and version, and on a page the element you picked. Pins mark each comment on the file. PDFs take no comments.

## Passing files on

Kernel can pass a file one teammate shared to another teammate. The receiver keeps the version Kernel sent, even after a newer one is shared.
