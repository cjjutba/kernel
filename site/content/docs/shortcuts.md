---
title: Keyboard shortcuts
description: Every shortcut Kernel listens for. Settings, Shortcuts has the same list with a filter.
---

## Workspaces

| Action | Shortcut |
| --- | --- |
| New chat | ⌘N |
| New tab | ⌘T |
| Close tab | ⌘W |
| Big terminal tab | ⌘⇧T |
| Create PR or mark ready | ⌘⇧P |
| Merge PR | ⌘⇧M |
| Fix conflicts, checks or review | ⌘⇧F |
| Archive merged or closed | ⌘⇧A |
| Open diff | ⌘⇧D |
| Run dev script | ⌘R |
| Open in default app | ⌘O |

## Agents

| Action | Shortcut |
| --- | --- |
| Approve request | ⌘↵ |
| Deny request | ⌘⌫ |
| Cycle the chat's mode, Plan included | ⇧Tab |
| Focus the message box | ⌘L |
| Open Kernel's chat | ⌘⇧L |
| Open the nth chat with Kernel | ⌘1 to ⌘9 |
| Open the nth workspace of this chat | ⌃1 to ⌃9 |
| Link issue | ⌘I |
| Add attachment | ⌘U |
| Pick model 1 to 4 | ⌃⌘1 to ⌃⌘4 |
| Cycle effort | ⌘⇧/ |

## App

| Action | Shortcut |
| --- | --- |
| Command palette | ⌘K |
| Settings | ⌘, |
| Toggle sidebar | ⌘B |
| Toggle right panel | ⌘⌥B or ⌘⇧B |
| Toggle bottom panel | ⌘J |
| Focus mode | ⌘\ |
| New chat | ⌘⇧N |
| Back | ⌘[ |
| Forward | ⌘] |

Hold ⌘ in the sidebar to see each row's number. The back and forward buttons on a mouse also go back and forward.
