---
title: Settings
description: Every page in Settings and what it holds. Search in Settings jumps straight to a setting.
---

Open Settings with ⌘, or the gear at the bottom of the sidebar. The search box at the top finds a page or a single setting, and lands on its row.

Personal settings live on your Mac. Each project's settings are on its own pages, described in [Project settings](/docs/project-settings).

## Personal

| Page | What it holds |
| --- | --- |
| General | Open at login, which screen Kernel opens to, and how the message box sends |
| Appearance | Theme, font size, density, reduce motion and pointer cursors |
| Notifications | Which events notify you, the sound, and quiet hours. See [Notifications](/docs/inbox#notifications) |
| Accounts | Claude Code and Codex accounts, usage, and what happens at a limit. See [Accounts](/docs/accounts) |
| Shortcuts | Every keyboard shortcut. See [Shortcuts](/docs/shortcuts) |

## Agents

| Page | What it holds |
| --- | --- |
| Models and effort | Each role's provider, model, effort and compacting, plan mode for new chats, how many agents work at once, and Keep Kernel updated |
| Agents | Your personal and plugin agents, and the agents new projects start with |
| MCP servers | Every MCP server, and which are ready on each account |
| Permissions | The permission mode, Always ask before, Never allow, protected branches, network access and the approval timeout. See [Permissions](/docs/permissions) |
| Environment | Variables every chat, script and terminal gets |

## Workspaces

| Page | What it holds |
| --- | --- |
| Git and worktrees | Workspace type, the branch to branch from, the remote, where worktrees go, branch names, setup and archive scripts, and archiving |
| Pull requests | Merge without asking me, its size limit and the paths you always review, the merge method, automatic review, and the instructions agents follow |
| Big terminal | What a new terminal tab runs, your own commands, and whether terminal tabs only open in worktrees |

## System

| Page | What it holds |
| --- | --- |
| Integrations | GitHub, Linear and Jira |
| Hooks | Kernel's Claude Code hooks, the settings file they live in, and the hook server's port, with a test event |
| Privacy | Whether to share anonymous usage data, and a list of every event kept or sent. See [Privacy](/docs/privacy) |
| About | The version and updates, the data folder, logs, and onboarding |
