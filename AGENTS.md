# Agents

Any coding agent working in this repo (Codex, Claude Code or another) follows [CLAUDE.md](CLAUDE.md). It has the commands, the rules and how to work an issue.

That includes its Release notes section: every PR that changes app files adds a one-sentence fragment in `.changes/unreleased/`, written by the agent making the change, with or without a Linear issue. CI fails the PR without one. See [.changes/README.md](.changes/README.md).
